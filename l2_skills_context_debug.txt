■ スキル名: skill-designer
  説明: スキル設計要件に基づいて新しいスキルを設計し、または既存スキルを再設計するツール。
  入力パラメータ仕様:
    * prompt (str) (必須): 設計するスキルの機能要件や追加の改修要望を記述した自然言語のテキスト。
    * summary (str) (任意): スキルの仕様概要（ビジネス目的や要求の要約）。指定した場合、Geminiによる自動要約より優先して design.json の summary フィールドに保存されます。
    * output_dir (str) (任意): 生成されたdesign.jsonを保存するディレクトリのパス。省略時はskillから自動探索されます。
    * skill (str) (任意): 既存のスキル名。再設計時の自動探索キーとして使用されます。
    * source_code_dir (str) (任意): 再設計のベースとなる既存のスキル実装コードのディレクトリ（またはファイル）パス。指定しない場合、自動的に検出を試みます。
  出力戻り値仕様:
    * status (str): 処理結果の成否ステータス（'success' / 'failed'）
    * message (str): 処理結果のメッセージサマリー
    * output_dir (str): 成果物(design.json)が格納されたスキルディレクトリの絶対パス

■ スキル名: skill-coder
  説明: 設計定義ファイル(design.json)と機能要件(prompt)に基づき、ADK 2.0規約およびオブジェクト指向設計に準拠したスキル実装コードを自動生成・更新するスキル。
  入力パラメータ仕様:
    * prompt (str) (任意): 実装したいビジネスロジックの機能要件や詳細な指示。
    * skill (str) (任意): 対象のスキル名。design_pathが省略された場合の探索キー。
    * design_path (str) (任意): 対象スキルの design.json への絶対/相対パス。
    * output_dir (str) (任意): ソースコードを出力するディレクトリ。省略時は対象スキルのルートディレクトリ。
  出力戻り値仕様:
    * status (str): スキルの実行結果ステータス ('success' または 'failed')
    * message (str): スキル実行結果の要約メッセージ
    * output_dir (str): 実装コードが出力されたディレクトリの絶対パス

■ スキル名: skill-spec-writer
  説明: 設計情報（Pydanticスキーマ等）を動的にロードし、ADK 2.0仕様に準拠したSKILL.mdを生成します。
  入力パラメータ仕様:
    * prompt (str) (任意): 仕様書生成における、特別に明記したい追加の表現上のこだわりや注意点などの指示。
    * design_path (str) (任意): design.json ファイルの直接のパス。省略された場合は skill から自動探索します。
    * skill (str) (任意): 対象の既存スキル名。design_path 省略時の自動探索キーとして使用されます。
    * output_dir (str) (任意): 生成されたSKILL.mdを保存するディレクトリのパス。省略時は対象スキルのディレクトリに出力されます。
    * source_code_dir (str) (任意): 実装ソースコードが格納されたディレクトリパス（または単一ファイル）。指定しない場合、自動的にスキルの scripts ディレクトリを探索します。
  出力戻り値仕様:
    * status (str): スキルの実行結果ステータス。'success' または 'failed'。
    * message (str): 実行結果に関する詳細メッセージ。
    * output_dir (str): 仕様書(SKILL.md)が格納されたスキルディレクトリの絶対パス
