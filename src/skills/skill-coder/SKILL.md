# skill-coder

## 概要

設計定義ファイル(design.json)と機能要件(prompt)に基づき、ADK 2.0規約およびオブジェクト指向設計に準拠したスキル実装コードを自動生成・更新するスキル。

### 主な機能
* 設計定義ファイル（design.json）と機能要件（prompt）に基づくスキル実装コードの自動生成と更新
* Pydanticモデル、ハンドラー、パッケージ初期化ファイルなどの決定論的なコード生成
* LLMエージェントによるビジネスロジックの実装と自己修正機能
* 生成されたPythonコードのコンパイルチェックとエラーフィードバックによる品質保証
* ワークフローエージェントの多段階ノード（スキル、関数、エージェント）のコード生成と接続

### 内部処理の流れ
1. 対象スキル名またはdesign.jsonへのパスから、実装対象のスキルを特定し、そのルートディレクトリを決定します。
2. 対象スキルのdesign.jsonをロードし、その内容を解析します。
3. CodeGeneratorを使用して、models.py、handler.py、__init__.pyなどの決定論的なコードファイルを生成します。
4. design.jsonの概要とユーザーが指定した機能要件（prompt）をマージし、SkillDeveloperAgentExecutorに渡すための包括的なプロンプトを作成します。
5. SkillDeveloperAgentExecutorを起動し、LLMエージェントがコード生成プロセスを開始します。エージェントはファイル読み書きツールやドキュメント参照ツールを活用します。
6. エージェントがコードを生成または修正した後、生成されたすべてのPythonファイルに対してpy_compileによるコンパイルチェックを実行します。
7. コンパイルエラーが検出された場合、エラー内容をエージェントにフィードバックし、自己修正を促すための新しいプロンプトを生成して再コーディングを試行します（最大3回）。
8. 最終的に生成または更新されたすべてのファイルの相対パスリストを収集し、実行結果として返します。

## トリガー条件

- 新しいスキルを実装してほしい
- 既存のスキルに機能を追加してほしい
- 〇〇という名前のスキルを生成して
- この設計書（design.json）に基づいてスキルコードを書いて
- ワークフローエージェントのコードを自動生成してほしい
- 〇〇スキルにバリデーションロジックを組み込んで

## AIエージェント向け使用方法

### 1. 実行手順（Instructions）

あなた（エージェント）がこのスキルをトリガーした場合は、以下の手順に従ってください。

1. 必要な入力パラメータを確認します。
2. スキル内部のテンプレート（`assets/prompt.txt` 等）をロードし、そこに記載されている指示および思考ステップに従って推論を行ってください。
3. 生成した成果物は、定義された出力形式（Output Mode）に厳密に従って出力してください。

> [!NOTE]
> **`prompt` パラメータの使用ガイドライン:**
> * **指定可能な指示**: 生成・修正したいビジネスロジック（例：APIクライアントの作成、バリデーションロジックの追加、ユーティリティ関数の実装など）の実装要件を指定できます。
> * **構造的な制約（指定不可）**: 自動生成される handler.py, models.py, __init__.py は編集できません。また、エグゼキューター（scripts/executor.py）の全体的なクラス構造やインターフェース（execute() メソッド）は固定されているため、これを逸脱するシグネチャ変更はできません。


### 2. 呼び出し方法
- **インプロセス呼び出し (Python API)**: ロード関数 `process_message(params, tool_context)` を使用。
- **サブプロセス呼び出し (CLI)**: CLIランナーを使用。
  `python3 -m edd_agent_tools.run skill-coder [オプション引数]`
- **出力形式 (Output Mode)**: `STRUCTURED_JSON` (特定のJSONスキーマ構造に厳密に従った構造化データを出力します。生成結果のパース成功時に生成されたファイルのパスや、エラー時にはエラーメッセージと詳細情報が含まれます。)

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| prompt | str | いいえ | 実装したいビジネスロジックの機能要件や詳細な指示。 |
| skill | str | いいえ | 対象のスキル名。design_pathが省略された場合の探索キー。 |
| design_path | str | いいえ | 対象スキルの design.json への絶対/相対パス。 |
| output_dir | str | いいえ | ソースコードを出力するディレクトリ。省略時は対象スキルのルートディレクトリ。 |

### 出力パラメータ (構造化JSONの戻り値構造)

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| status | str | はい | スキルの実行結果ステータス ('success' または 'failed') |
| message | str | はい | スキル実行結果の要約メッセージ |
| output_dir | str | はい | 実装コードが出力されたディレクトリの絶対パス |
