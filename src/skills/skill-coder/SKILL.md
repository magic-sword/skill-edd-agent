# スキル仕様書: skill-coder

## 概要

設計定義ファイル(design.json)と機能要件(prompt)に基づき、ADK 2.0規約およびオブジェクト指向設計に準拠したスキル実装コードを自動生成・更新するワークフロー。

### 主な機能
* 設計定義ファイル(design.json)と機能要件(prompt)に基づくスキル実装コードの自動生成。
* ADK 2.0規約およびオブジェクト指向設計に準拠したコード生成。
* 既存スキルのビジネスロジックコードの更新。
* Pydanticモデル、ハンドラー関数、パッケージ初期化ファイルなどの決定論的コードの生成。
* エージェント（LLM）による動的なビジネスロジックの実装と修正。
* 生成されたコードのコンパイルチェックと、エラー発生時のエージェントによる自己修復。

### 内部処理の流れ
1. ユーザーから提供された`prompt`、`skill`名、または`design_path`を検証し、対象スキルを特定する。
2. 特定されたスキルの`design.json`をロードし、設計定義情報を取得する。
3. `CodeGenerator`を使用して、Pydanticモデル(`models.py`)、ハンドラー関数(`handler.py`)、パッケージ初期化ファイル(`__init__.py`)、およびエグゼキューターのプレースホルダー(`executor.py`)といった決定論的なコードファイルを生成する。
4. `design.json`の概要とユーザーの`prompt`を統合し、`SkillDeveloperAgent`（LLM）への詳細な指示プロンプトを作成する。
5. `SkillDeveloperAgentExecutor`を初期化し、`SkillDeveloperAgent`を起動する。
6. `SkillDeveloperAgent`は、提供された指示とツール（ファイル読み書き、ドキュメント参照など）を用いて、ビジネスロジックの実装や既存コードの修正を行う。
7. コード生成後、生成されたすべてのPythonファイルに対して`py_compile`によるコンパイルチェックを実行し、構文エラーやインポートエラーがないか検証する。
8. コンパイルエラーが検出された場合、エラー内容を`SkillDeveloperAgent`にフィードバックし、最大3回まで自己修復を試みさせる。
9. 最終的なコード生成結果（ステータス、メッセージ、出力ディレクトリ、生成ファイルリスト）をユーザーに報告する。

## 公開関数

### skill_coder

設計定義ファイル(design.json)と機能要件(prompt)に基づき、ADK 2.0規約およびオブジェクト指向設計に準拠したスキル実装コードを自動生成・更新するワークフロー。

#### 実行方法
${skill_name} は、内部でLLMが自律的な**思考と推論**を行い、複雑なタスクを解決するエージェントです。このエージェントを呼び出す際は、解決したい課題を具体的に指示してください。

利用例：
${skill_name}(課題="〇〇を解決したい")

#### 入力パラメータ
| パラメータ名 | 型 | 必須 | デフォルト値 | 説明 |
|---|---|---|---|---|
| prompt | str | いいえ | - | 実装したいビジネスロジックの機能要件や詳細な指示。 |
| skill | str | いいえ | - | 対象のスキル名。design_pathが省略された場合の探索キー。 |
| design_path | str | いいえ | - | 対象スキルの design.json への絶対/相対パス。 |
| output_dir | str | いいえ | - | コードの出力先ディレクトリ。省略時は対象スキルのルートディレクトリ。 |


> [!NOTE]
> **`prompt` パラメータの使用ガイドライン:**
> * **指定可能な指示**: 生成・修正したいビジネスロジック（例：APIクライアントの作成、バリデーションロジックの追加、ユーティリティ関数の実装など）の実装要件を指定できます。
> * **構造的な制約（指定不可）**: 自動生成される handler.py, models.py, __init__.py は編集できません。また、エグゼキューター（scripts/executor.py）の全体的なクラス構造やインターフェース（execute() メソッド）は固定されているため、これを逸脱するシグネチャ変更はできません。


#### 出力仕様
* **出力モード**: `STRUCTURED_JSON`

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| status | str | はい | スキルの実行結果ステータス ('success' または 'failed') |
| message | str | はい | スキル実行結果の要約メッセージ |
| output_dir | str | はい | 実装コードが出力されたディレクトリの絶対パス |
