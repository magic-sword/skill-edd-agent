# skill-coder

## 概要

このスキルは、Google ADK 2.0 互換のスキル実装コードを自動生成・更新するためのツールです。与えられた設計定義ファイル（design.json）と詳細な機能要件（prompt）に基づき、オブジェクト指向設計原則に準拠したPythonコードを生成します。主な機能と処理フローは以下の通りです。*   **入力パラメータの解析と検証:** ユーザーから提供された機能要件（prompt）、対象スキル名（name）、または設計ファイルのパス（design_path）、出力ディレクトリ（output_dir）を解析し、必要なパラメータが揃っているか検証します。*   **ディレクトリ構造の準備:** 対象スキルのルートディレクトリ内に、scripts、assets、referencesといったADK 2.0の標準的なディレクトリ構造を確保します。*   **scripts/handler.pyの決定論的生成:** 対象スキルのdesign.jsonに定義されたパラメータ情報に基づき、PydanticモデルのInputクラス定義と、ビジネスロジックへのルーティングを担うscripts/handler.pyを自動的かつ決定論的に生成します。これにより、スキルの入力インターフェースがdesign.jsonと常に同期されます。*   **scripts/logic.pyのプレースホルダー配置:** スキルの主要なビジネスロジックを記述するためのscripts/logic.pyがまだ存在しない場合、基本的なテンプレートファイルを配置します。*   **AIエージェントによるコード生成・更新:**    *   内部でSkillDeveloperAgentという専用のAIエージェントを起動します。    *   このエージェントには、対象スキルの設計情報、機能要件、既存のソースコード、およびADK 2.0の開発規約がシステムプロンプトとして与えられます。    *   エージェントは、ReadFileTool、EditFileTool、WriteFileToolといったファイル操作ツールと、edd-agent-toolsライブラリのドキュメントを参照するツールを活用し、与えられた機能要件に従ってscripts/logic.pyなどのビジネスロジックコードを段階的に実装または更新します。    *   このプロセスは、AIエージェントが自律的に推論し、コードを生成・修正することで、複雑なビジネスロジックの実装を支援します。*   **結果の報告:** コード生成・更新が完了した後、生成または変更されたファイルの一覧を報告します。このスキルは、AIエージェントが直接推論して応答を生成するのではなく、引数を受け取ってPythonスクリプトとして動作し、その内部でさらに高度なAIエージェントを起動してコード生成タスクを完結させる「ツール」として機能します。

## AIエージェント向け使用方法

### 1. 実行手順（Instructions）

あなた（エージェント）がこのスキルをトリガーした場合は、以下の手順に従ってください。

1. 必要な入力パラメータ（`prompt`など）を決定します。
2. 決定したパラメータを指定して、このスキルを起動してください。
3. 実際の処理（API呼び出しやファイル出力など）は内部スクリプト側で完結するため、あなた自身が内部テンプレートを読み込んで推論したり、成果物を手動で組み立てたりする必要はありません。


### 2. 呼び出し方法
- **インプロセス呼び出し (Python API)**: ロード関数 `process_message` を使用（状態の `validated_input` に `Input` スキーマを設定して実行）。
- **サブプロセス呼び出し (CLI)**: CLIランナーを使用。
  `python3 -m edd_agent_tools.cli.run skill-coder [オプション引数]`
- **出力形式 (Output Mode)**: `STRUCTURED_JSON` (特定のJSONスキーマ構造に厳密に従った構造化データを出力します。生成結果のパース成功時に生成されたファイルのパスや、エラー時にはエラーメッセージと詳細情報が含まれます。)

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| prompt | str | はい | 実装したいビジネスロジックの機能要件や詳細な指示。 |
| name | str | いいえ | 対象のスキル名。design_pathが省略された場合の探索キー。 |
| design_path | str | いいえ | 対象スキルの design.json への絶対/相対パス。 |
| output_dir | str | いいえ | ソースコードを出力するディレクトリ。省略時は対象スキルのルートディレクトリ。 |

### 制約事項

- name または design_path のいずれか一方が必須であること。
