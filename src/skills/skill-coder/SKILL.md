# skill-coder

## 概要

設計定義ファイル(design.json)と機能要件(prompt)に基づき、ADK 2.0規約およびオブジェクト指向設計に準拠したスキル実装コードを自動生成・更新するスキル。

### 主な機能
* 設計定義ファイル（design.json）に基づくPydanticモデル、ハンドラー、初期化ファイルの自動生成
* ユーザーの機能要件（prompt）と設計概要を統合したAIエージェントによるビジネスロジックの実装
* 生成されたPythonコードに対するリアルタイムなコンパイルチェックと自己修復機能
* ツール型スキルとワークフロー型スキルの両方に対応したコード生成
* スキル開発に必要な共通ディレクトリとプレースホルダーファイルの自動配置

### 内部処理の流れ
1. 指定されたスキル名またはdesign.jsonパスから対象スキルを特定し、その設計定義（design.json）をロードします。
2. 設計定義に基づき、Pydanticモデル（models.py）、ハンドラー（handler.py）、パッケージ初期化ファイル（__init__.py）などの決定論的なコードファイルを生成します。
3. ユーザーの機能要件と設計定義の概要を結合し、AIエージェントへの詳細な指示プロンプトを作成します。
4. SkillDeveloperAgentExecutorを起動し、AIエージェントにビジネスロジックの実装または修正を指示します。
5. AIエージェントが生成または更新したPythonファイルに対して、`py_compile`によるコンパイルチェックを実行します。
6. コンパイルエラーが検出された場合、エラー内容をAIエージェントにフィードバックし、最大3回まで自己修復を試行させます。
7. すべてのコード生成と修正が完了した後、生成または更新されたファイルの相対パスリストを収集し、結果として返します。

## トリガー条件

- 〇〇というスキルをADK 2.0規約に沿って実装してください。
- この設計定義（design.json）に基づいて、新しいスキルコードを生成してほしい。
- 既存のスキルに、このビジネスロジック（prompt）を追加・修正してほしい。
- ADK 2.0互換のスキルを自動でコーディングして。
- 指定された機能要件を満たすPythonスキルコードを作成してください。
- スキル開発を手伝って。設計と要件はこれです。

## AIエージェント向け使用方法

### 1. 実行手順（Instructions）

あなた（エージェント）がこのスキルをトリガーした場合は、以下の手順に従ってください。

1. 必要な入力パラメータ（`prompt`, `skill`など）を決定します。
2. 決定したパラメータを指定して、このスキルを起動してください。
3. 実際の処理（API呼び出しやファイル出力など）は内部スクリプト側で完結するため、あなた自身が内部テンプレートを読み込んで推論したり、成果物を手動で組み立てたりする必要はありません。

> [!NOTE]
> **`prompt` パラメータの使用ガイドライン:**
> * **指定可能な指示**: 生成・修正したいビジネスロジック（例：APIクライアントの作成、バリデーションロジックの追加、ユーティリティ関数の実装など）の実装要件を指定できます。
> * **構造的な制約（指定不可）**: 自動生成される handler.py, models.py, __init__.py は編集できません。また、エグゼキューター（scripts/executor.py）の全体的なクラス構造やインターフェース（execute() メソッド）は固定されているため、これを逸脱するシグネチャ変更はできません。


### 2. 呼び出し方法
- **インプロセス呼び出し (Python API)**: ロード関数 `process_message(params, tool_context)` を使用。
- **サブプロセス呼び出し (CLI)**: CLIランナーを使用。
  `python3 -m edd_agent_tools.run skill-coder [オプション引数]`
- **出力形式 (Output Mode)**: `STRUCTURED_JSON` (特定のJSONスキーマ構造に厳密に従った構造化データを出力します。生成結果のパース成功時に生成されたファイルのパスや、エラー時にはエラーメッセージと詳細情報が含まれます。)

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| prompt | str | いいえ | 実装したいビジネスロジックの機能要件や詳細な指示。 |
| skill | str | いいえ | 対象のスキル名。design_pathが省略された場合の探索キー。 |
| design_path | str | いいえ | 対象スキルの design.json への絶対/相対パス。 |
| output_dir | str | いいえ | ソースコードを出力するディレクトリ。省略時は対象スキルのルートディレクトリ。 |

### 出力パラメータ (構造化JSONの戻り値構造)

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| status | str | はい | スキルの実行結果ステータス ('success' または 'failed') |
| message | str | はい | スキル実行結果の要約メッセージ |
| output_dir | str | はい | 実装コードが出力されたディレクトリの絶対パス |
