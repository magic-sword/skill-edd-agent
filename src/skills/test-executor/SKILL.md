# test-executor

## 概要

指定されたスキルに対してADK評価シミュレーションを実行し、その結果を検証します。

### 主な機能
* 指定されたスキルに対してADK評価シミュレーションを実行します。
* 評価結果を定義された精度閾値（0.0〜1.0）に基づいて検証し、合否を判断します。
* 評価セットの識別子（'trigger'、'unit'）またはファイルパスを指定して、柔軟なテストデータ選択を可能にします。
* 評価のタイムアウト秒数を設定し、実行時間を制御します。
* 評価設定ファイルのパスを指定することで、詳細な評価設定を適用できます。

### 内部処理の流れ
1. 入力パラメータとツールコンテキストを使用して`SkillExecutor`を初期化します。
2. 評価対象スキルの名前と評価セットのパスを取得し、`SkillRegistry`から対象スキルと評価オブジェクトを特定します。
3. 評価のタイムアウト秒数と合格に必要な精度閾値を取得します。
4. 指定された評価セットに対してADK評価シミュレーションを実行します。
5. 実行された評価結果を分析し、精度が閾値以上であるかを確認して合否を判断します。
6. 評価結果（ステータス、メッセージ、精度、閾値）を`ToolContext.state`に更新します。
7. 合格した場合は成功メッセージを返し、失敗した場合はエラーメッセージと共に`RuntimeError`を発生させます。

## トリガー条件

- スキル「[スキル名]」のADK評価を実行してください。
- 「[スキル名]」の評価シミュレーションを開始してください。
- 評価セット「[評価セットパス]」を使用してスキル「[スキル名]」のテストを実行してください。
- スキル「[スキル名]」の精度を「[閾値精度]」で検証してください。
- 「[スキル名]」の動作確認をしたいです。
- このスキルの評価結果を教えてください。

## AIエージェント向け使用方法

### 1. 実行手順（Instructions）

あなた（エージェント）がこのスキルをトリガーした場合は、以下の手順に従ってください。

1. 必要な入力パラメータ（`skill`など）を決定します。
2. 決定したパラメータを指定して、このスキルを起動してください。
3. 実際の処理（API呼び出しやファイル出力など）は内部スクリプト側で完結するため、あなた自身が内部テンプレートを読み込んで推論したり、成果物を手動で組み立てたりする必要はありません。


### 2. 呼び出し方法
- **インプロセス呼び出し (Python API)**: ロード関数 `process_message(params, tool_context)` を使用。
- **サブプロセス呼び出し (CLI)**: CLIランナーを使用。
  `python3 -m edd_agent_tools.run test-executor [オプション引数]`
- **出力形式 (Output Mode)**: `VALUE_ONLY` (出力は単純なプレーンテキストの値のみとなります。)

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| skill | str | はい | 評価対象スキルの名前。 |
| eval_set_path | str | いいえ | 評価セットの識別子（'trigger' または 'unit'）、あるいはファイルパス。デフォルトは 'trigger'。 |
| config_file_path | str | いいえ | 評価設定ファイルのパス。指定しない場合は自動解決・自動生成されます。 |
| timeout_seconds | int | いいえ | 評価のタイムアウト秒数。デフォルトは 180 秒。 |
| threshold_accuracy | float | いいえ | 合格に必要な精度の閾値（0.0 から 1.0）。デフォルトは 1.0。 *(制約: 最小値: 0.0, 最大値: 1.0)* |

### 出力値

スキル実行結果を示す単一のテキストメッセージ（プレーンテキスト）が返されます。
