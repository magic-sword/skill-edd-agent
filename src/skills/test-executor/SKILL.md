# test-executor

## 概要

この `test-executor` スキルは、Google ADK (Agent Development Kit) の `adk eval` コマンドを安全なサブプロセス環境で実行し、指定されたスキルのテストを自動的に評価するためのツールです。AIエージェントが直接推論を行うのではなく、引数として受け取ったパラメータに基づいてPythonスクリプトが決定論的な処理を完結させます。主な機能と処理の流れは以下の通りです。

*   **テスト対象の指定**: `skill` パラメータでテスト対象のスキル名を、`eval_set_path` パラメータでテストケースファイル（例: `*.evalset.json`）のパスを指定します。パスは絶対パスまたは `/workspace` からの相対パスで指定可能です。
*   **評価設定ファイルの決定**: まず、指定されたテストケースファイルと同じディレクトリに、`[テストファイル名].evalset.config.json` という名前の設定ファイルが存在するかを確認します。見つからない場合、テストケースファイルがあるディレクトリ内で `eval_config.json` または `test_config.json` という一般的な設定ファイルを探します。いずれも見つからない場合は、`test-executor` スキルのアセットディレクトリに、`response_match_score` のみで判定し、軌跡評価を除外するデフォルト設定ファイル（`default_eval_config.json`）を生成し、それを使用します。
*   **ADK eval の実行**: 決定された設定ファイルとテストケースファイルを使用して、`adk eval` コマンドを新しいサブプロセスとして実行します。この際、`timeout_seconds` で指定された時間制限（デフォルト180秒）が適用されます。また、評価エンジンが多言語環境で正しく動作するための `PYTHONPATH` 環境変数のパッチ適用も行われます。
*   **結果の解析と合否判定**: `adk eval` の標準出力および標準エラー出力を解析し、テストの合格数、不合格数、および全体に対する精度を算出します。ログから正確な数値が抽出できない場合でも、`adk eval` の終了コードに基づいて合否をフォールバック判定します（正常終了なら精度1.0、異常終了なら精度0.0）。算出された精度が `threshold_accuracy` パラメータ（デフォルト1.0、つまり100%合格）で指定された閾値以上であれば「合格」、そうでなければ「不合格」と判定されます。
*   **結果の格納**: 最終的な合否ステータス、メッセージ、算出された精度、および閾値は `ToolContext.state` に格納され、後続の処理やユーザーへのフィードバックに利用されます。
*   **エラー処理**: ファイルが見つからない場合や、テスト実行がタイムアウトした場合、またはその他の予期せぬエラーが発生した場合は、適切なエラーメッセージと共に処理が中断され、`RuntimeError` が発生します。このツールは、CI/CDパイプラインや自動テスト環境において、スキルの品質を保証するために不可欠なコンポーネントとして機能します。

## AIエージェント向け使用方法

### 1. 実行手順（Instructions）

あなた（エージェント）がこのスキルをトリガーした場合は、以下の手順に従ってください。

1. 必要な入力パラメータ（`skill`, `eval_set_path`など）を決定します。
2. 決定したパラメータを指定して、このスキルを起動してください。
3. 実際の処理（API呼び出しやファイル出力など）は内部スクリプト側で完結するため、あなた自身が内部テンプレートを読み込んで推論したり、成果物を手動で組み立てたりする必要はありません。


### 2. 呼び出し方法
- **インプロセス呼び出し (Python API)**: ロード関数 `process_message` を使用（状態の `validated_input` に `Input` スキーマを設定して実行）。
- **サブプロセス呼び出し (CLI)**: CLIランナーを使用。
  `python3 -m edd_agent_tools.cli.run test-executor [オプション引数]`
- **出力形式 (Output Mode)**: `VALUE_ONLY` (出力は単純なプレーンテキストの値のみとなります。)

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| skill | str | はい | テスト対象のスキル名。 |
| eval_set_path | str | はい | テストケースファイル（*.evalset.json）の絶対パス、または src ディレクトリからの相対パス。 |
| threshold_accuracy | float | いいえ | 合格に必要な精度の閾値（0.0 から 1.0 の浮動小数点）。デフォルトは 1.0 (100%合格)。 |
| timeout_seconds | int | いいえ | テスト実行のタイムアウト制限（秒）。デフォルトは 180 秒。 |
| eval_mode | int | いいえ | 評価モード。デフォルトは 1。 |

### 制約事項

- threshold_accuracy は 0.0 から 1.0 の範囲である必要があります。
- eval_mode は 0 または 1 のいずれかである必要があります。
