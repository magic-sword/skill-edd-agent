# test-executor

## 概要

このスキルは、指定されたADKスキルに対して評価テスト（adk eval）を実行し、その結果を解析して合否を判定するツールです。AIエージェントが直接推論するのではなく、引数として受け取ったパラメータに基づき、Pythonスクリプトが以下の処理を決定論的に実行します。

主な機能と処理フロー：
*   **テスト設定ファイルの決定:**
    *   `eval_set_path`で指定されたテストケースファイル（例: `*.evalset.json`）に対応する評価設定ファイル（例: `*.evalset.config.json`）を検索します。
    *   見つからない場合は、テストケースファイルがあるディレクトリ内の一般的な設定ファイル（`eval_config.json`、`test_config.json`）を探します。
    *   いずれも見つからない場合、`response_match_score`のみを評価基準とするデフォルト設定ファイルを自動生成して使用します。
*   **ADK評価の実行:**
    *   指定された`skill_name`と決定された設定ファイル、`eval_set_path`を用いて、`adk eval`コマンドを安全なサブプロセスとして実行します。
    *   `timeout_seconds`で指定された時間内にテストが完了しない場合、タイムアウトエラーを発生させます。
    *   `eval_mode`パラメータにより、評価モード（単体テスト評価用またはトリガー評価用）を制御します。
*   **結果の解析と合否判定:**
    *   `adk eval`コマンドの標準出力およびエラー出力から、合格・不合格のテスト数を抽出し、全体の精度を算出します。
    *   ログからの抽出が困難な場合は、コマンドの終了コードに基づいてフォールバック判定を行います（正常終了なら精度1.0、異常終了なら0.0）。
    *   算出された精度が`threshold_accuracy`で指定された閾値以上であれば「合格」、そうでなければ「不合格」と判定します。
*   **結果の報告:**
    *   テストのステータス（合格/不合格）、メッセージ、算出された精度、および閾値が`ToolContext.state`に格納されます。
    *   不合格の場合、`RuntimeError`を発生させて処理を中断します。

このツールは、スキルの品質保証や継続的インテグレーションのパイプラインにおいて、自動的なテスト実行と評価を行うために利用されます。

## トリガー条件

- 「〇〇スキル」のテストを実行してください。
- 「〇〇.evalset.json」を使ってスキル評価を行ってください。
- 「〇〇スキル」の精度が「0.9」以上か確認してください。
- 「〇〇スキル」のテスト結果を教えてください。
- 「〇〇スキル」のADK evalを実行して。
- 「〇〇スキル」のテストを「180秒」のタイムアウトで実行して。

## AIエージェント向け使用方法

### 1. 実行手順（Instructions）

あなた（エージェント）がこのスキルをトリガーした場合は、以下の手順に従ってください。

1. 必要な入力パラメータ（`skill_name`, `eval_set_path`など）を決定します。
2. 決定したパラメータを指定して、このスキルを起動してください。
3. 実際の処理（API呼び出しやファイル出力など）は内部スクリプト側で完結するため、あなた自身が内部テンプレートを読み込んで推論したり、成果物を手動で組み立てたりする必要はありません。


### 2. 呼び出し方法

このスキルは、インプロセス（Python関数のロード）による親エージェントとのシームレスな連携、およびCLIを用いた手動での検証実行をサポートします。

#### インプロセス呼び出し (Python API)
他の親エージェントから直接ロードして呼び出す場合は、以下のインターフェースを使用します。

* **ロード関数名**: `process_message`
* **入力状態 (`tool_context.state`)**:
  * `tool_context.state["validated_input"]` に、`Input` スキーマのインスタンス（検証済みオブジェクト）が設定されます。
* **出力状態 (`tool_context.state`)**:
  * 処理結果データが状態に直接書き込まれます。

#### サブプロセス呼び出し (CLI)
* **起動方法**: `python3 -m edd_agent_tools.cli.run --skill_name test-executor <引数>`
* **引数 (`args`)**:
  * Pydantic スキーマで定義されているパラメータをフラットなオプション引数として直接渡します（例: `--param_name value`）。

#### 出力形式の要件 (Output Mode)
- **Output Mode: VALUE_ONLY**
  出力は単純なプレーンテキストの値のみとなります。

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| skill_name | str | はい | テスト対象のスキル名。 |
| eval_set_path | str | はい | テストケースファイル（*.evalset.json）の絶対パス、または src ディレクトリからの相対パス。 |
| threshold_accuracy | float | いいえ | 合格に必要な精度の閾値（0.0 から 1.0 の浮動小数点）。デフォルトは 1.0 (100%合格)。 |
| timeout_seconds | int | いいえ | テスト実行のタイムアウト制限（秒）。デフォルトは 180 秒。 |
| eval_mode | int | いいえ | 評価モード。デフォルトは 1。 |



### 実行例

#### 1. インプロセス呼び出し (推奨)
親エージェントが本スキルを動的ロードしてプログラムから起動する推奨コード例です。

```python
# 1. スキルのロード
skill = load_skill("test-executor")

# 2. 状態に引数を設定して実行
# ※ 引数は validated_input 経由で process_message に渡されます
# tool_context.state["validated_input"] = Input(...)
skill.process_message(tool_context)
```

#### 2. サブプロセス呼び出し (手動テスト用 CLI)
開発環境などで本スキルを手動で動作確認する際の起動コマンド例です。

```bash
python3 -m edd_agent_tools.cli.run --skill_name test-executor --name "target-skill-name"
```
