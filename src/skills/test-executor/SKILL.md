# test-executor

## 概要

この test-executor スキルは、Google ADK (Agent Development Kit) を用いて開発された特定のスキルに対して、自動テストを実行し、その結果を評価するためのツールです。AIエージェント（LLM）が推論を行うのではなく、与えられた引数に基づいてPythonスクリプトが決定論的にテスト処理を完結させます。

### 主な機能と処理の流れ

1.  **入力パラメータの受け取り**:
    *   `skill`: テスト対象となるスキル名を指定します。
    *   `eval_set_path`: テストケースが記述された `.evalset.json` ファイルのパスを指定します。絶対パスまたは `src` ディレクトリからの相対パスが可能です。
    *   `threshold_accuracy`: テストが「合格」と判定されるために必要な精度の閾値（0.0から1.0の浮動小数点数）を指定します。デフォルトは1.0（100%合格）です。
    *   `timeout_seconds`: テスト実行の最大時間（秒）を指定します。デフォルトは180秒です。

2.  **ADK eval 設定ファイルの決定**:
    *   まず、指定された `eval_set_path` に対応する特定の設定ファイル（例: `[テスト名].evalset.config.json`）を検索します。
    *   見つからない場合、`eval_set_path` が存在するディレクトリ内で一般的な設定ファイル（`eval_config.json` や `test_config.json`）を検索します。
    *   いずれも見つからない場合は、`test-executor` スキルのアセットディレクトリにデフォルトの設定ファイル（`default_eval_config.json`）を生成し、これを使用します。このデフォルト設定は、`response_match_score` のみで評価を行い、軌跡評価などを除外します。

3.  **ADK eval の実行**:
    *   決定された設定ファイルと入力パラメータを使用して、`adk eval` コマンドを安全なサブプロセスとして実行します。
    *   この際、多言語対応のためのパッチ環境変数（`PYTHONPATH`）が設定され、テスト対象のスキルが正しく評価されるようにします。
    *   指定された `timeout_seconds` を超えた場合、テスト実行は強制的に終了され、タイムアウトエラーとして処理されます。

4.  **テスト結果の解析と精度計算**:
    *   `adk eval` コマンドの標準出力と標準エラー出力を解析し、「Tests passed」と「Tests failed」の数を抽出します。
    *   これらの情報に基づいて、テストの精度（`passed / total`）を計算します。
    *   ログから結果を正確に抽出できなかった場合でも、`adk eval` の終了コード（0: 成功、非0: 失敗）に基づいてフォールバックの精度（1.0または0.0）を決定します。

5.  **合否判定と結果の報告**:
    *   計算された精度が `threshold_accuracy` 以上であるかを確認し、テストの最終的な合否を判定します。
    *   結果（合否ステータス、メッセージ、計算された精度、閾値）は、`ToolContext.state` に格納されます。
    *   テストが不合格またはタイムアウトした場合は、適切なエラーメッセージとともに処理が中断されます。

このスキルは、開発者がスキルの品質を継続的に検証し、期待される動作を保証するために不可欠な自動テストプロセスをサポートします。

## トリガー条件

- 「[スキル名]」の ADK eval テストを実行して
- 「[テストケースファイル]」を使ってスキルを評価して
- スキルのテストを実行し、精度が「[閾値]」以上か確認して
- 「[スキル名]」のテストを「[タイムアウト秒数]」秒以内に完了させて
- テストセット「[ファイルパス]」で「[スキル名]」の動作を検証して

## AIエージェント向け使用方法

### 1. 実行手順（Instructions）

あなた（エージェント）がこのスキルをトリガーした場合は、以下の手順に従ってください。

1. 必要な入力パラメータ（`skill`, `eval_set_path`など）を決定します。
2. 決定したパラメータを指定して、このスキルを起動してください。
3. 実際の処理（API呼び出しやファイル出力など）は内部スクリプト側で完結するため、あなた自身が内部テンプレートを読み込んで推論したり、成果物を手動で組み立てたりする必要はありません。


### 2. 呼び出し方法
- **インプロセス呼び出し (Python API)**: ロード関数 `process_message` を使用（状態の `validated_input` に `Input` スキーマを設定して実行）。
- **サブプロセス呼び出し (CLI)**: CLIランナーを使用。
  `python3 -m edd_agent_tools.cli.run test-executor [オプション引数]`
- **出力形式 (Output Mode)**: `VALUE_ONLY` (出力は単純なプレーンテキストの値のみとなります。)

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| skill | str | はい | テスト対象のスキル名。 |
| eval_set_path | str | はい | テストケースファイル（*.evalset.json）の絶対パス、または src ディレクトリからの相対パス。 |
| threshold_accuracy | float | いいえ | 合格に必要な精度の閾値（0.0 から 1.0 の浮動小数点）。デフォルトは 1.0 (100%合格)。 |
| timeout_seconds | int | いいえ | テスト実行のタイムアウト制限（秒）。デフォルトは 180 秒。 |

### 制約事項

- threshold_accuracy は 0.0 から 1.0 の範囲である必要があります。
