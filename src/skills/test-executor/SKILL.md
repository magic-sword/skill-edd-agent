# test-executor

## 概要

このスキルは、AIエージェントが引数を受け取り、特定のスキルに対してADK評価テストを実行するためのツールです。Gemini呼び出しを含む実機実行評価を行い、その結果を判定して返します。

### 主な機能
* 指定されたスキルに対してADK評価テストを実行します。
* 評価設定ファイルを自動的に解決または生成します。
* 指定された精度閾値に基づいてテストの合否を判定します。
* 評価結果（ステータス、メッセージ、精度など）をToolContext.stateに格納します。
* 評価対象スキル、テストデータセット、設定ファイル、タイムアウト、精度閾値などの詳細なパラメータ設定をサポートします。

### 内部処理の流れ
1. 入力パラメータから評価対象スキル、テストデータセットパス、精度閾値、タイムアウト秒数を取得します。
2. 評価対象スキルのディレクトリを特定し、必要に応じてテストデータセットパスを自動解決します。
3. 評価設定ファイルのパスを解決または自動生成し、存在しない場合はデフォルト設定で作成します。
4. 必要な環境変数を設定します。
5. ADKEvalRunnerを使用してADK評価テストを実行します。
6. テスト結果から精度を算出し、指定された閾値と比較して合否を判定します。
7. 評価のステータス、メッセージ、精度、閾値などの詳細な結果をToolContext.stateに格納します。
8. 合否判定に基づき、結果メッセージを返却するか、エラーを発生させます。

## トリガー条件

- スキル「〇〇」の評価テストを実行してください。
- 「〇〇」のADK評価を開始して。
- 指定されたスキルに対してテストを実行したいです。
- 評価セットパス「〇〇」を使ってスキル「〇〇」のテストを行ってください。
- スキル「〇〇」の精度が閾値「〇〇」以上か確認してほしい。
- テスト結果を評価して。

## AIエージェント向け使用方法

### 1. 実行手順（Instructions）

あなた（エージェント）がこのスキルをトリガーした場合は、以下の手順に従ってください。

1. 必要な入力パラメータ（`skill`など）を決定します。
2. 決定したパラメータを指定して、このスキルを起動してください。
3. 実際の処理（API呼び出しやファイル出力など）は内部スクリプト側で完結するため、あなた自身が内部テンプレートを読み込んで推論したり、成果物を手動で組み立てたりする必要はありません。


### 2. 呼び出し方法
- **インプロセス呼び出し (Python API)**: ロード関数 `process_message(params, tool_context)` を使用。
- **サブプロセス呼び出し (CLI)**: CLIランナーを使用。
  `python3 -m edd_agent_tools.run test-executor [オプション引数]`
- **出力形式 (Output Mode)**: `VALUE_ONLY` (出力は単純なプレーンテキストの値のみとなります。)

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| skill | str | はい | 評価対象スキルの名前またはパス。 |
| eval_set_path | str | いいえ | テストデータセットファイルのパス。 |
| config_file_path | str | いいえ | 評価設定ファイルのパス。 |
| timeout_seconds | int | いいえ | 評価のタイムアウト秒数。 |
| threshold_accuracy | float | いいえ | 合格に必要な精度の閾値（0.0 から 1.0 の浮動小数点）。デフォルトは 1.0。 *(制約: 最小値: 0.0, 最大値: 1.0)* |
