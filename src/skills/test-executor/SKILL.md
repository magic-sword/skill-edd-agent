# test-executor

## 概要

このスキルは、指定されたGoogle ADK 2.0互換スキルに対して、定義されたテストセット（`*.evalset.json`ファイル）を用いた評価（`adk eval`コマンド）を自動的に実行するツールです。AIエージェントが推論を行うのではなく、引数として与えられたパラメータに基づいてPythonスクリプトが処理を完結させます。

主な機能と動作は以下の通りです。

*   **テスト実行の自動化**: `skill_name`と`eval_set_path`で指定されたスキルとテストセットに対し、`adk eval`コマンドを安全なサブプロセスとして実行します。
*   **設定ファイルの管理**:
    *   テストセットファイル名に対応する設定ファイル（例: `[test_name].evalset.config.json`）を優先的に探索します。
    *   見つからない場合は、テストセットがあるディレクトリ内の一般的な設定ファイル（`eval_config.json`や`test_config.json`）を探します。
    *   いずれも見つからない場合は、`response_match_score`のみを評価基準とするデフォルト設定ファイルを自動生成して使用します。
*   **結果の解析と合否判定**:
    *   `adk eval`の標準出力およびエラー出力から、合格したテスト数と不合格だったテスト数を抽出し、全体の精度を算出します。
    *   抽出に失敗した場合は、`adk eval`コマンドの終了コードに基づいて合否をフォールバック判定します（正常終了なら精度1.0、異常終了なら精度0.0）。
    *   算出された精度が、`threshold_accuracy`パラメータで指定された閾値以上であれば「合格」、そうでなければ「不合格」と判定します。
*   **タイムアウト処理**: `timeout_seconds`パラメータで指定された時間内にテストが完了しない場合、実行を中断し、タイムアウトエラーとして処理します。
*   **評価モードの指定**: `eval_mode`パラメータにより、評価の挙動を制御できます（例: 単体テスト評価用、トリガー評価用）。

このツールは、スキルの品質保証プロセスにおいて、自動化されたテスト実行と結果評価を効率的に行うことを目的としています。

## AIエージェント向け使用方法

### 1. 実行手順（Instructions）

あなた（エージェント）がこのスキルをトリガーした場合は、以下の手順に従ってください。

1. 必要な入力パラメータ（`skill_name`, `eval_set_path`など）を決定します。
2. 決定したパラメータを指定して、このスキルを起動してください。
3. 実際の処理（API呼び出しやファイル出力など）は内部スクリプト側で完結するため、あなた自身が内部テンプレートを読み込んで推論したり、成果物を手動で組み立てたりする必要はありません。


### 2. 呼び出し方法
- **インプロセス呼び出し (Python API)**: ロード関数 `process_message` を使用（状態の `validated_input` に `Input` スキーマを設定して実行）。
- **サブプロセス呼び出し (CLI)**: CLIランナーを使用。
  `python3 -m edd_agent_tools.cli.run test-executor [オプション引数]`
- **出力形式 (Output Mode)**: `VALUE_ONLY` (出力は単純なプレーンテキストの値のみとなります。)

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| skill_name | str | はい | テスト対象のスキル名。 |
| eval_set_path | str | はい | テストケースファイル（*.evalset.json）の絶対パス、または src ディレクトリからの相対パス。 |
| threshold_accuracy | float | いいえ | 合格に必要な精度の閾値（0.0 から 1.0 の浮動小数点）。デフォルトは 1.0 (100%合格)。 |
| timeout_seconds | int | いいえ | テスト実行のタイムアウト制限（秒）。デフォルトは 180 秒。 |
| eval_mode | int | いいえ | 評価モード。デフォルトは 1。 |

### 制約事項

- threshold_accuracyは0.0から1.0の範囲である必要があります。
- eval_modeは0または1である必要があります。
