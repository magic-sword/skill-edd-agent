# skill-designer

## 概要

このスキルは、Google ADK 2.0 互換の `design.json` ファイルを自動的に設計・生成するためのツールです。ユーザーが指定した自然言語の機能要件に基づいて、新しいスキルをゼロから設計したり、既存のスキルを再設計したりすることができます。AIエージェントが直接推論を行うのではなく、引数を受け取ってPythonスクリプトが処理を完結させる決定論的なツールとして機能します。

主な機能と内部処理の流れは以下の通りです。

*   **入力の受け付け**:
    *   設計するスキルの機能要件を記述した自然言語テキスト（`requirement`）を受け取ります。
    *   生成された `design.json` を保存するディレクトリパス（`output_dir`）や、再設計の対象となる既存のスキル名（`name`）、既存スキルの実装コードのパス（`source_code_dir`）をオプションで受け取ります。
    *   `output_dir` または `name` のいずれか一方は必須です。
*   **スキルディレクトリの解決**:
    *   指定されたスキル名または出力ディレクトリに基づいて、対象となるスキルフォルダを特定します。
    *   既存スキルを再設計する場合は、そのスキルから既存の制約事項（バリデーションルールなど）を抽出し、設計のコンテキストとして利用します。
*   **プロンプトの構築**:
    *   `skill-designer` スキル自身の内部アセットとして定義されているプロンプトテンプレートをロードします。
    *   このテンプレートに、ユーザーから与えられた機能要件、既存スキルの情報、抽出された制約事項などを組み込み、Gemini API に渡すためのプロンプトを整形します。
    *   既存のソースコードディレクトリが指定されている場合、その内容をGemini APIのコンテキストとして添付します。
    *   さらに、プロジェクト共通の開発規約（`README.md`）もコンテキストとして追加し、より適切な設計が行われるようにします。
*   **Gemini API の呼び出し**:
    *   構築されたプロンプトとコンテキスト（ソースコード、規約など）を `gemini-2.5-flash` モデルに送信します。
    *   レスポンスは `application/json` 形式で、`SkillDesign` スキーマに準拠するよう指定されます。これにより、構造化された設計データが確実に返されます。
*   **design.json の保存**:
    *   Gemini API から返された JSON データをパースし、指定された出力ディレクトリ内の `assets` サブディレクトリに `design.json` として保存します。
    *   保存が完了すると、成功メッセージと出力ファイルのパスがツールコンテキストに設定されます。

このスキルを利用することで、開発者はスキル設計プロセスを自動化し、効率的にスキルを開発できるようになります。

## トリガー条件

- 新しいスキルを設計してほしい。
- 〇〇という機能を持つスキルを作成してください。
- 既存のスキル「〇〇」を再設計したい。
- この要件に基づいてスキルデザインを生成してください。
- 指定されたソースコードを元に、スキル「〇〇」のdesign.jsonを更新して。
- スキル設計のドラフトを作成してほしい。

## AIエージェント向け使用方法

### 1. 実行手順（Instructions）

あなた（エージェント）がこのスキルをトリガーした場合は、以下の手順に従ってください。

1. 必要な入力パラメータ（`requirement`など）を決定します。
2. 決定したパラメータを指定して、このスキルを起動してください。
3. 実際の処理（API呼び出しやファイル出力など）は内部スクリプト側で完結するため、あなた自身が内部テンプレートを読み込んで推論したり、成果物を手動で組み立てたりする必要はありません。


### 2. 呼び出し方法
- **インプロセス呼び出し (Python API)**: ロード関数 `process_message` を使用（状態の `validated_input` に `Input` スキーマを設定して実行）。
- **サブプロセス呼び出し (CLI)**: CLIランナーを使用。
  `python3 -m edd_agent_tools.cli.run skill-designer [オプション引数]`
- **出力形式 (Output Mode)**: `STRUCTURED_JSON` (特定のJSONスキーマ構造に厳密に従った構造化データを出力します。生成結果のパース成功時に生成されたファイルのパスや、エラー時にはエラーメッセージと詳細情報が含まれます。)

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| requirement | str | はい | 設計するスキルの機能要件を記述した自然言語のテキスト。 |
| output_dir | str | いいえ | 生成されたdesign.jsonを保存するディレクトリのパス。省略時はnameから自動探索されます。 |
| name | str | いいえ | 既存のスキル名。再設計時の自動探索キーとして使用されます。 |
| source_code_dir | str | いいえ | 再設計のベースとなる既存のスキル実装コードのディレクトリ（またはファイル）パス。指定しない場合、自動的に検出を試みます。 |

### 制約事項

- output_dir と name のいずれか一方は必ず指定する必要があります。
