# skill-designer

## 概要

この skill-designer スキルは、Google ADK 2.0 互換のスキルまたはエージェントを設計するための統合されたエントリポイントとして機能します。ユーザーは target_type パラメータで設計対象がスキルかエージェントかを指定し、name でその名称を、requirement で自然言語による機能要件を、output_dir で生成される設計ファイル（通常は design.json）の保存先ディレクトリを指定します。本スキルは、これらの入力パラメータを解析し、内部の process_message 関数を通じて、与えられた要件に基づいた詳細な設計情報を生成します。これにより、開発者は自然言語の要件から直接、構造化された設計仕様書を得ることができ、開発プロセスの効率化を支援します。

## トリガー条件

- 新しいスキルを設計したい
- エージェントの設計を開始
- この要件でスキルを設計して: [要件]
- スキル設計ツールを起動して
- 指定された要件に基づいてスキルを生成してほしい

## AIエージェント向け使用方法

このスキルは、インプロセス（Python関数のロード）およびサブプロセス（`run_skill_script`によるCLI実行）の双方の実行モードをサポートします。

### 1. インプロセス呼び出し (Python API)
ワークフローや他の親エージェントから直接ロードして呼び出す場合は、以下のインターフェースを使用します。

* **ロード関数名**: `process_message`
* **入力状態 (`tool_context.state`)**:
  * スキルのパラメータが直接状態（キー/値）として設定されます。
* **出力状態 (`tool_context.state`)**:
  * 処理の成否や結果データが直接状態に書き込まれます。

### 2. サブプロセス呼び出し (CLI)
* **実行ファイル**: `scripts/main.py`
* **引数 (`args`)**:
  * `input_json`: パラメータ情報を含む JSON 文字列
  * `output_json`: 結果を一時保存するファイルパス

### 3. 出力形式の要件 (Output Mode)

- **Output Mode: STRUCTURED_JSON**
  設計されたスキルまたはエージェントの完全な仕様をJSON形式で出力します。このJSONには、入力された機能要件、定義されたパラメータ、依存関係、および設計プロセスによって導出されたその他の詳細な設計要素が含まれます。出力は、後続のツールやプロセスで利用可能な構造化データとして提供されます。

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| target_type | str | はい | 設計対象のタイプ（例: 'skill', 'agent'） |
| name | str | はい | 設計するスキルまたはエージェントの名前 |
| requirement | str | はい | 設計のための自然言語による機能要件 |
| output_dir | str | はい | 生成されたdesign.jsonを保存するディレクトリパス |

### 実行例 (サブプロセス)

```python
run_skill_script(
    file_path="scripts/main.py",
    args={
        "input_json": "{\"param\": \"value\"}",
        "output_json": "/workspace/src/.workflow_tmp/output.json"
    }
)
```
