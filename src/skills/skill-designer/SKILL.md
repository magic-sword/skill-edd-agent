# skill-designer

## 概要

このスキルは、自然言語で記述された機能要件や既存のソースコードを基に、ADK 2.0 互換の design.json を設計・生成する決定論的なツールです。新しいスキルの設計や既存スキルの再設計を自動化し、開発プロセスを効率化します。

### 主な機能
* 自然言語の要件に基づいた新規スキルの設計
* 既存のスキルコードを解析し、再設計を支援
* ADK 2.0 互換の design.json ファイルの生成
* 既存スキルの制約事項を自動抽出し、設計に反映
* プロジェクト共通開発規約を設計コンテキストに含める

### 内部処理の流れ
1. 入力パラメータ（要件、出力ディレクトリ、スキル名、ソースコードディレクトリ）を抽出します。
2. 指定されたスキル名または出力ディレクトリに基づいて、対象スキルのディレクトリと出力パスを解決します。
3. 既存のスキルが存在する場合、その入力スキーマから制約事項を抽出し、設計の参考情報とします。
4. スキルデザイナーのプロンプトテンプレートをロードし、要件、既存スキル名、抽出された制約事項で整形します。
5. Gemini APIに渡すコンテンツリストを構築し、必要に応じて既存のソースコードやプロジェクト共通開発規約を追加します。
6. Gemini APIを呼び出し、SkillDesignスキーマに準拠したdesign.jsonの内容を生成します（一時的なエラーに対してリトライ処理を行います）。
7. 生成されたdesign.jsonデータをパースし、指定された出力ディレクトリ内のassetsフォルダにファイルとして保存します。
8. 処理の成功メッセージと生成されたファイルのパスをツールコンテキストに設定し、ユーザーに結果を通知します。

## トリガー条件

- 新しいスキルを設計してほしい。
- この機能要件でスキルを設計してください。
- 既存のスキルを再設計したい。
- 〇〇という名前のスキルを、このソースコードを基に更新して。
- スキル設計のドラフトを作成してほしい。
- design.jsonファイルを生成してください。

## AIエージェント向け使用方法

### 1. 実行手順（Instructions）

あなた（エージェント）がこのスキルをトリガーした場合は、以下の手順に従ってください。

1. 必要な入力パラメータ（`requirement`など）を決定します。
2. 決定したパラメータを指定して、このスキルを起動してください。
3. 実際の処理（API呼び出しやファイル出力など）は内部スクリプト側で完結するため、あなた自身が内部テンプレートを読み込んで推論したり、成果物を手動で組み立てたりする必要はありません。


### 2. 呼び出し方法
- **インプロセス呼び出し (Python API)**: ロード関数 `process_message(params, tool_context)` を使用。
- **サブプロセス呼び出し (CLI)**: CLIランナーを使用。
  `python3 -m edd_agent_tools.run skill-designer [オプション引数]`
- **出力形式 (Output Mode)**: `STRUCTURED_JSON` (特定のJSONスキーマ構造に厳密に従った構造化データを出力します。生成結果のパース成功時に生成されたファイルのパスや、エラー時にはエラーメッセージと詳細情報が含まれます。)

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| requirement | str | はい | 設計するスキルの機能要件を記述した自然言語のテキスト。 |
| output_dir | str | いいえ | 生成されたdesign.jsonを保存するディレクトリのパス。省略時はskillから自動探索されます。 |
| skill | str | いいえ | 既存のスキル名。再設計時の自動探索キーとして使用されます。 |
| source_code_dir | str | いいえ | 再設計のベースとなる既存のスキル実装コードのディレクトリ（またはファイル）パス。指定しない場合、自動的に検出を試みます。 |

### 出力パラメータ (構造化JSONの戻り値構造)

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| name | string | はい | スキルの名前 |
| description | string | はい | スキルの目的や役割を記述した簡潔な説明（L1 description用） |
| execution_type | Literal['tool', 'agent'] | はい | 実行タイプ。'tool' (スクリプト処理) または 'agent' (LLM推論) |
| output_mode | Literal['VALUE_ONLY', 'CONVERSATIONAL', 'STRUCTURED_JSON'] | はい | 出力形式 |
| parameters | array | はい | スキルが受け取るパラメータのリスト |
| dependencies | array | いいえ | スキルが依存する他のスキルのリスト |
| constraints | array | いいえ | モデルバリデータ等から抽出された制約条件のリスト |
| response_parameters | array | いいえ | 出力(戻り値)JSONのパラメータ構造定義。STRUCTURED_JSON時に使用されます |

### 制約事項

- output_dir と skill のいずれか一方は必ず指定する必要があります。
