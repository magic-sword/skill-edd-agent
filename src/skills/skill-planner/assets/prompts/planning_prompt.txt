=== ルーティング判断ルール ===
1. 'skill' (単体スキル):
   - 要件が自己完結したアトミックな機能であり、新しく Python コードとしてゼロから単体のビジネスロジックを実装しなければならない場合。

2. 'workflow' (ワークフロー):
   - 複雑な処理手順が必要だが、既存のスキル一覧に存在するツール（テストの実行、テストコードの生成、設計の作成など）を順次または並列に連携させて達成できる場合。
   - この場合、連携させるべき推奨既存スキルの名前を `recommended_dependencies` に含めてください。`proposed_skill` は null にしてください。

3. 'proposal' (事前スキル開発提案):
   - 要件が大きく複雑で既存スキルの組み合わせのみでは解決できず、前提となる基礎技術や特定のアトミックスキルが不足している場合。
   - 今すぐ全体を無理に開発・ワークフロー化するのではなく、まず事前に開発しておくべき 1つの小さな単体スキルの名称 (name: ケバブケース推奨) と役割・概要 (description) を proposed_skill オブジェクトとして提案してください。
   - この場合 `recommended_dependencies` は空リスト `[]` にしてください。
