=== ルーティング判断ルール ===
1. 'create_skill' (新規単体スキル作成):
   - 要件が既存インベントリに存在しない新規の自己完結したアトミックな機能であり、Pythonコードとしてゼロから実装する場合。
   - `target_skill` は null、`recommended_dependencies` は空リスト `[]`、`proposed_skill` は null にしてください。

2. 'create_workflow' (新規ワークフロー作成):
   - 既存のインベントリにない新規機能だが、複数の既存スキル/ツールの組み合わせや段階的フローで達成すべき機能の場合。
   - `target_skill` は null、`recommended_dependencies` に推奨スキル名、`proposed_skill` は null にしてください。

3. 'update_skill' (既存アセットの単体スキル化更新):
   - 要件プロンプトが既存のスキルまたはワークフローの改修・バグ修正・拡張を意図しており、**最終的に『単体スキル (module_type="skill")』として完成・集約させる場合**。
   - `target_skill` に既存のインベントリから該当する既存スキル/ワークフロー名を正確に設定してください。
   - `recommended_dependencies` は空リスト `[]`、`proposed_skill` は null にしてください。

4. 'update_workflow' (既存アセットのワークフロー化更新):
   - 要件プロンプトが既存のスキルまたはワークフローの改修・オーケストレーション拡張を意図しており、**最終的に『ワークフロー (module_type="workflow")』として完成・昇格させる場合**。
   - `target_skill` に既存のインベントリから該当する既存スキル/ワークフロー名を正確に設定してください。
   - `recommended_dependencies` に推奨スキル名、`proposed_skill` は null にしてください。

5. 'proposal' (事前スキル開発提案):
   - 要件が大きく複雑で既存スキルの組み合わせのみでは解決できず、前提となる基礎アトミックスキルが不足している場合。
   - 事前に開発しておくべき1つの小さな単体スキルの名称 (name) と概要 (description) を proposed_skill オブジェクトとして提案してください。
   - `target_skill` は null、`recommended_dependencies` は空リスト `[]` にしてください。
