# スキル仕様書: trigger-test-executor

## 概要

指定された評価セットに基づき、対象スキルのインテント分類シミュレーションを行い、予測結果と期待値を比較して合格件数と精度を算出します。

### 主な機能
* 指定された評価セットに基づいたインテント分類シミュレーションの実行
* LLMによるユーザー発話からのスキル呼び出し予測
* 予測結果と期待値の比較によるテストケースの合否判定
* テスト全体の合格件数、失敗件数、総数、精度の集計
* 詳細なテスト結果のJSONファイルへの保存

### 内部処理の流れ
1. ユーザーから評価対象スキル名と評価セットパスを受け取る。
2. 指定されたパスから評価セット（TrajectoryEvalSet形式のJSON）をロードし、パースする。
3. ワークスペースに登録されている全てのスキル（SKILL.mdを含む）をロードし、インテント分類の候補として準備する。
4. 評価セット内の各テストケース（会話ターン）について、以下の処理を繰り返す。
5. ユーザー発話と、その発話で期待されるスキル呼び出し（正例/負例）を特定する。
6. 収集した全スキル情報とユーザー発話に基づき、LLMにどのスキルが呼び出されるべきかを予測させる。
7. LLMの予測結果とテストケースの期待値を比較し、合否を判定する。
8. 各テストケースの詳細な検証結果を記録する。
9. 全てのテストケースの検証が完了した後、合格数、失敗数、総数、精度を集計する。
10. 集計された結果と、各テストケースの詳細な検証結果をファイルに保存し、最終結果をユーザーに報告する。

## トリガー条件

このスキルは、以下の条件やプロンプトでトリガーされます。

- 「[スキル名]のトリガー評価テストを実行して」
- 「[評価セットファイルパス]を使って、[スキル名]のインテント分類テストを行って」
- 「新しいスキルのインテントが正しく分類されるか確認したい」
- 「トリガーテストを実行して、結果を教えて」

## 公開関数

### execute

トリガー（インテント）評価テストを実行し、その結果を検証します。

#### 実行方法
${skill_name} は、内部でLLMが自律的な**思考と推論**を行い、複雑なタスクを解決するエージェントです。このエージェントを呼び出す際は、解決したい課題を具体的に指示してください。

利用例：
${skill_name}(課題="〇〇を解決したい")

#### 入力パラメータ
| パラメータ名 | 型 | 必須 | デフォルト値 | 説明 |
|---|---|---|---|---|
| skill_name | str | はい | - | 評価対象となるスキルの名前。 |
| eval_set_path | str | はい | - | TrajectoryEvalSet形式のJSONファイルへのパス。 |


#### 出力仕様
* **出力モード**: `STRUCTURED_JSON`

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| passed | int | はい | 合格したテストケースの数。 |
| failed | int | はい | 失敗したテストケースの数。 |
| total | int | はい | 実行されたテストケースの総数。 |
| accuracy | float | はい | テストの精度（合格数 / 総数）。 |
| detail_file_path | str | いいえ | 詳細なテスト結果が保存されたファイルのパス（任意）。 |


---

### 制約事項

- eval_set_pathで指定されるファイルは、TrajectoryEvalSet形式の有効なJSONである必要があります。
- LLMによるインテント分類シミュレーションの精度は、提供されるSKILL.mdの品質とLLMの性能に依存します。
