# skill-generator

## 概要

このスキルは、Google ADK 2.0 のサブエージェント（SkillDeveloperAgent）を動的に起動し、指定された要件に基づいて新しいスキルを自律的に生成・実装するエージェントタイプのスキルです。

**主な機能と動作フロー:**
*   **要件の解析とエージェントの初期化:** ユーザーから提供された詳細なプロンプト（要件）を受け取り、それに基づいてスキル名や出力ディレクトリなどのパス情報を解析します。
*   **プロンプトテンプレートのロードと適用:** 内部に保持するプロンプトテンプレート（`assets/system_instruction.txt`）をロードし、スキル名や出力ディレクトリなどの動的な情報を埋め込むことで、`SkillDeveloperAgent` のシステム指示を構築します。これにより、LLMは具体的なタスクと制約を理解して推論を実行します。
*   **開発環境の準備:** 指定された出力ディレクトリ内に、`scripts`、`references`、`assets` などの必要なフォルダ構造を自動的に作成します。また、`SKILL.md`、`skill_script.py`、`handler.py` などのテンプレートファイルをコピーし、初期設定を行います。
*   **サブエージェントの実行:** 構築されたシステム指示とユーザーの要件プロンプトを用いて `SkillDeveloperAgent` を起動します。このサブエージェントは、以下のツールを活用してスキル開発タスクを遂行します。
    *   `ReadFileTool`: ファイルの内容を読み込みます。
    *   `EditFileTool`: ファイルの内容を編集します。
    *   `WriteFileTool`: 新しいファイルを書き込みます。
    *   `LibraryDocumentationReader`: `edd_agent_tools` などの共通ライブラリの公式ドキュメントを動的に読み込み、参照します。
*   **進捗の監視と出力:** サブエージェントの推論プロセス中に発生するメッセージやツール実行のログをリアルタイムでコンソールに出力し、開発の進捗を可視化します。
*   **結果の検証と報告:** スキル生成が完了した後、指定された出力ディレクトリに `SKILL.md` が正しく生成されたことを確認し、成功または失敗のステータスとメッセージを含むJSONファイルを生成します。

## AIエージェント向け使用方法

### 1. 実行手順（Instructions）

あなた（エージェント）がこのスキルをトリガーした場合は、以下の手順に従ってください。

1. 必要な入力パラメータを確認します。
2. スキル内部のテンプレート（`assets/prompt.txt` 等）をロードし、そこに記載されている指示および思考ステップに従って推論を行ってください。
3. 生成した成果物は、定義された出力形式（Output Mode）に厳密に従って出力してください。


### 2. 呼び出し方法
- **インプロセス呼び出し (Python API)**: ロード関数 `process_message` を使用（状態の `validated_input` に `Input` スキーマを設定して実行）。
- **サブプロセス呼び出し (CLI)**: CLIランナーを使用。
  `python3 -m edd_agent_tools.cli.run skill-generator [オプション引数]`
- **出力形式 (Output Mode)**: `VALUE_ONLY` (出力は単純なプレーンテキストの値のみとなります。)

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| output_dir | str | はい | 生成されたスキルが出力されるディレクトリパス。このパスの末尾のディレクトリ名が生成されるスキル名として使用されます。例: src/skills/my-skill |
| prompt | str | はい | 生成したいスキルの目的や要件を記述した詳細なプロンプト |
| model | str | いいえ | スキル生成に使用するLLMのモデル名 |
| max_attempts | int | いいえ | サブエージェントがスキル生成を試行する最大ターン数 |

### 制約事項

- output_dirは、スキル名として有効なケバブケース文字列を末尾に含むパスである必要があります。
