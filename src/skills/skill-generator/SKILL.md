# skill-generator

## 概要

このスキルは、Google ADK 2.0 のサブエージェントである SkillDeveloperAgent を動的に起動し、ユーザーが指定した要件に基づいて新しいスキルを自律的に生成・実装する強力なツールです。

## 主な機能と動作
*   **自律的なスキル開発**: ユーザーが提供する詳細なプロンプト（要件）を基に、SkillDeveloperAgent がスキル（SKILL.md、scripts/*.py など）のコードをゼロから開発します。
*   **プロンプトテンプレートの活用**: スキル内部に定義されたプロンプトテンプレート（例: assets/system_instruction.txt）をロードし、これに沿って SkillDeveloperAgent が思考プロセスを進めます。これにより、エージェントは一貫した開発ガイドラインに従って作業を行います。
*   **開発環境のセットアップ**: 指定された出力ディレクトリ（output_dir）に、新しいスキルのための基本的なディレクトリ構造（scripts、references、assets）を自動的に作成します。また、SKILL.md や handler.py などの初期テンプレートファイルを展開し、開発の足がかりを提供します。
*   **豊富な開発ツール**: SkillDeveloperAgent は、以下のツール群を活用して開発作業を進めます。
    *   ReadFileTool: ファイルの内容を読み込みます。
    *   EditFileTool: ファイルの内容を編集します。
    *   WriteFileTool: 新しいファイルを書き込みます。
    *   LibraryDocumentationReader: 共通ライブラリ（edd_agent_toolsなど）の公式ドキュメントを読み込み、参照します。
*   **反復的な開発プロセス**: SkillDeveloperAgent は、与えられた要件と利用可能なツールを用いて、最大試行回数（max_attempts）の範囲内でコードの記述、テスト、修正を繰り返しながら、目標とするスキルを完成させます。開発の進行状況はコンソールにリアルタイムで出力されます。

## 利用シナリオ
このスキルは、特定の機能を持つ新しいADKスキルを迅速にプロトタイプ作成したい場合や、複雑な要件に基づいてAIにスキル実装を任せたい場合に特に有用です。ユーザーは具体的な要件を提示するだけで、AIがその実現に向けたコード生成とファイル構成を行います。

## AIエージェント向け使用方法

### 1. 実行手順（Instructions）

あなた（エージェント）がこのスキルをトリガーした場合は、以下の手順に従ってください。

1. 必要な入力パラメータを確認します。
2. スキル内部のテンプレート（`assets/prompt.txt` 等）をロードし、そこに記載されている指示および思考ステップに従って推論を行ってください。
3. 生成した成果物は、定義された出力形式（Output Mode）に厳密に従って出力してください。


### 2. 呼び出し方法
- **インプロセス呼び出し (Python API)**: ロード関数 `process_message` を使用（状態の `validated_input` に `Input` スキーマを設定して実行）。
- **サブプロセス呼び出し (CLI)**: CLIランナーを使用。
  `python3 -m edd_agent_tools.cli.run skill-generator [オプション引数]`
- **出力形式 (Output Mode)**: `CONVERSATIONAL` (ユーザーとの対話を継続する会話形式の応答を出力します。)

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| output_dir | str | はい | 生成されたスキルが出力されるディレクトリのパス。例: src/skills/my-skill |
| prompt | str | はい | 生成したいスキルの詳細な説明や要件。 |
| model | str | いいえ | スキル生成に使用するLLMのモデル名。 |
| max_attempts | int | いいえ | スキル開発サブエージェントの最大試行（ターン）回数。 |
