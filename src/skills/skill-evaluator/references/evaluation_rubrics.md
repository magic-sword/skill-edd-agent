# Evaluation Rubrics & Quality Thresholds

本ドキュメントは、自己進化型 EDD エージェントにおけるスキルの評価基準、閾値、および採点ルーブリックの仕様を定義したものです。

## 1. Tier 昇格要件マトリクス

| Tier 階層 | 名称 | 必須テスト要件 | 合格閾値 | 昇格時アクション |
| :--- | :--- | :--- | :--- | :--- |
| **Tier 0** | `SANDBOX` | 静的バリデーション (`SkillValidator`) | エラー 0 件 | 生成直後の初期状態 |
| **Tier 1** | `PRODUCTION` | 依存関係 DAG 検証 + 契約テスト + トリガーテスト | 契約 100%, トリガー ≥ 90% | システム標準ツールとしてマウント |
| **Tier 2** | `VERIFIED` | Tier 1 要件 + ゴールデンテスト + ルーブリックジャッジ | ゴールデン ≥ 90%, ジャッジ ≥ 85% | 高信頼性スキルとして優先利用 |
| **Tier 3** | `MASTERED` | Tier 2 要件 + 推論軌跡テスト + 敵対的テスト | 軌跡 100%, 敵対的 ≥ 90% | 最高品質スキルとして他エージェントへ継承 |

## 2. LLM-as-a-Judge 評価ルーブリック (85点以上で合格)

1. **正確性 (Accuracy - Weight: 40%)**:
   - 仕様書 (SKILL.md) の指示および制約に忠実に従っているか。
   - 不要なハルシネーションや未定義のパラメータ利用がないか。
2. **完全性 (Completeness - Weight: 30%)**:
   - ユーザーの要求したすべての成果物・ファイルが生成されているか。
   - 必要なエッジケース処理が含まれているか。
3. **文体・トーン (Tone & Imperative Style - Weight: 15%)**:
   - 会話調や冗長表現を排し、動詞起点（Imperative）の客観的指示になっているか。
4. **リソース分離性 (Resource Separation - Weight: 15%)**:
   - 3層（`scripts/`, `references/`, `assets/`）の責務が正しく分離されているか。
