# mock-executor

## 概要

## 概要
このスキルは、Google ADK (Agent Development Kit) を用いて開発されたスキルのモックシミュレーション評価を実行するための専用ツールです。AIエージェントが直接推論するのではなく、与えられた引数に基づきPythonスクリプトとして決定論的な処理を完結させます。

### 主な機能
*   **スキル評価の自動化**: 指定されたスキルとテストデータセット（`eval_set_path`）を用いて、自動的に評価プロセスを実行します。
*   **柔軟な設定ファイル管理**: 
    *   テストデータセットに対応する評価設定ファイル（例: `[test_name].evalset.config.json`）を優先的に探索します。
    *   見つからない場合は、テストデータセットと同じディレクトリ内の一般的な設定ファイル（`eval_config.json`、`test_config.json`）を探します。
    *   いずれも見つからない場合は、`response_match_score`のみを評価基準とするデフォルト設定ファイルを自動生成し、それを使用します。これにより、軌跡評価（trajectory evaluation）を意図的に除外した評価が可能です。
*   **ADK Evalの実行**: `adk eval`コマンドをサブプロセスとして実行し、評価対象スキルに対してモック実行モード（`MOCK_TOOLS='load_skill'`環境変数を設定）でテストを行います。
*   **結果の解析と合否判定**: `adk eval`の標準出力からテスト結果（合格数、不合格数）を解析し、精度を算出します。算出された精度が指定された閾値（`threshold_accuracy`）以上であれば「合格」、そうでなければ「不合格」と判定します。
*   **タイムアウト制御**: 評価プロセスが指定された時間（`timeout_seconds`）を超過した場合、自動的に処理を終了し、デッドロックを防ぎます。
*   **詳細な結果出力**: 評価のステータス、メッセージ、精度、閾値などの詳細な結果を`ToolContext.state`に格納し、後続の処理やユーザーへのフィードバックに利用できるようにします。

### 内部処理の流れ
1.  **パラメータの取得と検証**: `skill`（評価対象スキル名またはパス）と`eval_set_path`（テストデータセットパス）が必須パラメータとして渡されていることを確認します。オプションの`config_file_path`、`timeout_seconds`、`threshold_accuracy`も取得します。
2.  **設定ファイルの決定**: `ConfigManager`が、上記「柔軟な設定ファイル管理」のロジックに従って、評価に使用する設定ファイルのパスを決定します。
3.  **ADK Evalの実行**: `TestRunner`が、決定された設定ファイルとその他のパラメータ（スキル名、テストデータセットパス、タイムアウト秒数）を用いて`adk eval`コマンドをサブプロセスとして実行します。この際、`MOCK_TOOLS='load_skill'`環境変数を設定し、モック実行を強制します。
4.  **出力の解析**: `OutputParser`が、`adk eval`コマンドの標準出力とエラー出力を解析し、テストの合格数、不合格数、合計数、そして精度を抽出します。解析に失敗した場合は、`adk eval`の終了コードに基づいて精度を推定します。
5.  **合否判定と結果格納**: 算出された精度と`threshold_accuracy`を比較し、評価の合否を判定します。この結果（ステータス、メッセージ、精度など）は`ToolContext.state`に格納されます。
6.  **エラーハンドリング**: ファイルが見つからない場合や、`adk eval`の実行中にエラーが発生した場合、またはタイムアウトした場合など、様々な例外を捕捉し、適切なエラーメッセージと共に処理を終了します。

## トリガー条件

- 〇〇スキルのモックシミュレーション評価を実行して
- 〇〇のテストデータセットを使ってスキルを評価してください
- 〇〇スキルの精度を測定して、閾値〇〇で合否を判定して
- 〇〇のシミュレーションテストを実施して結果を教えて
- 〇〇スキルが正しく動作するか、テストを実行して確認して
- 〇〇スキルに対して、〇〇秒のタイムアウトで評価を実行して

## AIエージェント向け使用方法

### 1. 実行手順（Instructions）

あなた（エージェント）がこのスキルをトリガーした場合は、以下の手順に従ってください。

1. 必要な入力パラメータ（`skill`, `eval_set_path`など）を決定します。
2. 決定したパラメータを指定して、このスキルを起動してください。
3. 実際の処理（API呼び出しやファイル出力など）は内部スクリプト側で完結するため、あなた自身が内部テンプレートを読み込んで推論したり、成果物を手動で組み立てたりする必要はありません。


### 2. 呼び出し方法
- **インプロセス呼び出し (Python API)**: ロード関数 `process_message` を使用（状態の `validated_input` に `Input` スキーマを設定して実行）。
- **サブプロセス呼び出し (CLI)**: CLIランナーを使用。
  `python3 -m edd_agent_tools.cli.run mock-executor [オプション引数]`
- **出力形式 (Output Mode)**: `VALUE_ONLY` (出力は単純なプレーンテキストの値のみとなります。)

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| skill | str | はい | 評価対象スキルの名前またはパス |
| eval_set_path | str | はい | テストデータセットファイルのパス |
| config_file_path | str | いいえ | 評価設定ファイルのパス |
| timeout_seconds | int | いいえ | 評価のタイムアウト秒数 |
| threshold_accuracy | float | いいえ | 合格に必要な精度の閾値（0.0 から 1.0 の浮動小数点）。デフォルトは 1.0。 |

### 制約事項

- threshold_accuracy は 0.0 から 1.0 の範囲である必要があります。
