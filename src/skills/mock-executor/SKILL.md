# mock-executor

## 概要

このスキルは、与えられた引数に基づきPythonスクリプトとして動作し、指定されたスキルのモック実行（シミュレーション）評価を実行します。評価結果を解析し、設定された精度閾値に基づいて合否を判定することで、スキルの品質検証を支援します。

### 主な機能
* 指定されたスキルに対してADK評価コマンドをモックモードで実行します。
* 評価実行の標準出力からテストの合格数、不合格数、合計数、および精度を解析します。
* 設定された精度の閾値に基づいて、スキルの評価が合格か不合格かを判定します。
* 評価設定ファイルが存在しない場合に、自動的にデフォルト設定ファイルを生成します。
* 評価実行中のタイムアウトを監視し、指定された時間を超えた場合に処理を中断します。

### 内部処理の流れ
1. ツールコンテキストから入力パラメータ（評価対象スキル名、テストデータセットパス、設定ファイルパス、タイムアウト秒数、精度閾値）を取得し、必須パラメータの存在を検証します。
2. 評価対象スキルのディレクトリから評価設定ファイルのパスを解決し、ファイルが存在しない場合はデフォルト設定を生成して保存します。
3. adk evalコマンドをサブプロセスとして実行し、評価対象スキル、テストデータセット、設定ファイル、タイムアウト秒数を引数として渡します。この際、モック実行を指示する環境変数MOCK_TOOLS='load_skill'を設定します。
4. adk evalコマンドの標準出力とエラー出力を取得し、そこからテストの合格数、不合格数、合計数、および精度を解析します。
5. 解析された精度と入力された精度閾値を比較し、評価の合否を判定します。
6. 評価結果（ステータス、メッセージ、精度、閾値）をツールコンテキストの状態に格納します。
7. 評価が不合格の場合、または予期せぬエラーが発生した場合は、適切なエラーメッセージとともに例外を発生させます。

## トリガー条件

- スキル〇〇のモックテストを実行してください
- テストデータセット〇〇を使ってスキル〇〇のシミュレーション評価を開始して
- 精度〇〇%以上でスキル〇〇の評価を実行して
- スキル〇〇の評価を〇〇秒以内に完了させて
- 〇〇スキルの評価結果を確認したい
- 〇〇のテストを走らせて

## AIエージェント向け使用方法

### 1. 実行手順（Instructions）

あなた（エージェント）がこのスキルをトリガーした場合は、以下の手順に従ってください。

1. 必要な入力パラメータ（`skill`, `eval_set_path`など）を決定します。
2. 決定したパラメータを指定して、このスキルを起動してください。
3. 実際の処理（API呼び出しやファイル出力など）は内部スクリプト側で完結するため、あなた自身が内部テンプレートを読み込んで推論したり、成果物を手動で組み立てたりする必要はありません。


### 2. 呼び出し方法
- **インプロセス呼び出し (Python API)**: ロード関数 `process_message` を使用（状態の `validated_input` に `Input` スキーマを設定して実行）。
- **サブプロセス呼び出し (CLI)**: CLIランナーを使用。
  `python3 -m edd_agent_tools.cli.run mock-executor [オプション引数]`
- **出力形式 (Output Mode)**: `VALUE_ONLY` (出力は単純なプレーンテキストの値のみとなります。)

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| skill | str | はい | 評価対象スキルの名前またはパス |
| eval_set_path | str | はい | テストデータセットファイルのパス |
| config_file_path | str | いいえ | 評価設定ファイルのパス |
| timeout_seconds | int | いいえ | 評価のタイムアウト秒数 |
| threshold_accuracy | float | いいえ | 合格に必要な精度の閾値（0.0 から 1.0 の浮動小数点）。デフォルトは 1.0。 |

### 制約事項

- threshold_accuracy は 0.0 から 1.0 の範囲である必要があります。
