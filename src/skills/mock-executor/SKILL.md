# mock-executor

## 概要

指定されたスキルに対してADK評価シミュレーションを実行し、その結果を検証します。

### 主な機能
* 指定されたスキルに対するADK評価シミュレーションの実行
* 評価セット（トリガー、ユニット、またはファイルパス）に基づくスキルの動作検証
* 設定可能な精度閾値を用いた評価の合否判定
* 評価のタイムアウト設定と評価設定ファイルの利用
* 評価結果の詳細なメッセージとステータスの提供

### 内部処理の流れ
1. 入力パラメータから評価対象スキル名と評価セットパスを取得し、必須パラメータの検証を行います。
2. SkillRegistryから指定されたスキル定義を取得し、評価セットオブジェクトを初期化します。
3. 設定されたタイムアウト秒数と設定ファイルパスを用いて、ADK評価シミュレーションを実行します。
4. 評価結果（精度、合否など）を取得し、指定された精度閾値と比較して最終的な合否を判断します。
5. 評価のステータス、メッセージ、精度、閾値などの詳細をツールコンテキストの状態に保存します。
6. 評価が合格基準を満たしていれば成功メッセージを返し、満たしていなければエラーメッセージとともに処理を終了します。

## AIエージェント向け使用方法

### 1. 実行手順（Instructions）

あなた（エージェント）がこのスキルをトリガーした場合は、以下の手順に従ってください。

1. 必要な入力パラメータ（`skill`など）を決定します。
2. 決定したパラメータを指定して、このスキルを起動してください。
3. 実際の処理（API呼び出しやファイル出力など）は内部スクリプト側で完結するため、あなた自身が内部テンプレートを読み込んで推論したり、成果物を手動で組み立てたりする必要はありません。

> [!NOTE]
> **`skill` パラメータの使用ガイドライン:**
> * **指定可能な指示**: 評価を実行したいスキルの名前を正確に指定してください。
> * **構造的な制約（指定不可）**: 必須項目です。


> [!NOTE]
> **`eval_set_path` パラメータの使用ガイドライン:**
> * **指定可能な指示**: 評価セットのタイプ（'trigger' または 'unit'）を指定するか、評価セットファイルへのパスを指定してください。
> * **構造的な制約（指定不可）**: デフォルトは 'trigger' です。


### 2. 呼び出し方法
- **インプロセス呼び出し (Python API)**: ロード関数 `process_message(params, tool_context)` を使用。
- **サブプロセス呼び出し (CLI)**: CLIランナーを使用。
  `python3 -m edd_agent_tools.run mock-executor [オプション引数]`
- **出力形式 (Output Mode)**: `VALUE_ONLY` (出力は単純なプレーンテキストの値のみとなります。)

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| skill | str | はい | 評価対象スキルの名前。 |
| eval_set_path | str | いいえ | 評価セットの識別子（'trigger' または 'unit'）、あるいはファイルパス。デフォルトは 'trigger'。 |
| config_file_path | str | いいえ | 評価設定ファイルのパス。指定しない場合は自動解決・自動生成されます。 |
| timeout_seconds | int | いいえ | 評価のタイムアウト秒数。デフォルトは 180 秒。 |
| threshold_accuracy | float | いいえ | 合格に必要な精度の閾値（0.0 から 1.0）。デフォルトは 1.0。 *(制約: 最小値: 0.0, 最大値: 1.0)* |

### 出力値

スキル実行結果を示す単一のテキストメッセージ（プレーンテキスト）が返されます。
