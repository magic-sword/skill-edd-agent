# mock-executor

## 概要

このスキルは、AIエージェントが引数を受け取り、Pythonスクリプトとして内部で処理を完結させるツールです。特定のスキルのモック実行（シミュレーション）評価を実行し、その結果をToolContext.stateに格納することで、スキルの品質を検証します。

### 主な機能
* 指定されたスキルのモック実行評価を実行します。
* 評価結果（合否、精度、メッセージなど）をToolContext.stateに格納します。
* 評価データセットパスが未指定の場合、対象スキルのトリガーテスト用データセットを自動的に解決します。
* 評価設定ファイルパスを自動的に解決または生成します。
* 設定された精度閾値に基づいて評価の合否を判定します。

### 内部処理の流れ
1. 評価対象スキルの名前、評価データセットパス、精度閾値、タイムアウト秒数などのパラメータを取得します。
2. 評価対象スキルが指定されていることを確認し、スキルレジストリから対象スキルのディレクトリを取得します。
3. 評価データセットパスが指定されていない場合、対象スキルのトリガーテスト用データセットパスを自動的に解決します。
4. 評価設定ファイルパスを解決し、存在しない場合はデフォルト設定で生成します。
5. 必要な環境変数（例: GEMINI_API_KEY）を設定します。
6. ADKEvalRunnerを使用して、指定されたスキルに対してモック実行評価を実行します。
7. 実行結果から精度を取得し、設定された閾値と比較して合否を判定します。
8. 評価のステータス、メッセージ、精度、閾値などの詳細をToolContext.stateに格納します。
9. 評価が合格した場合は成功メッセージを返し、不合格の場合はエラーメッセージと共にRuntimeErrorを発生させます。
10. ファイルが見つからないエラーやその他の実行時エラーを捕捉し、ToolContext.stateを更新して再スローします。

## トリガー条件

- スキルのモック評価を実行してほしい
- [スキル名]のテストシミュレーションを開始してください
- [スキル名]の評価を実行してください
- スキルの精度を検証したい
- 評価データセット[パス]を使って[スキル名]のテストを行ってください
- [スキル名]の評価を[閾値]の精度で実行してください

## AIエージェント向け使用方法

### 1. 実行手順（Instructions）

あなた（エージェント）がこのスキルをトリガーした場合は、以下の手順に従ってください。

1. 必要な入力パラメータ（`skill`など）を決定します。
2. 決定したパラメータを指定して、このスキルを起動してください。
3. 実際の処理（API呼び出しやファイル出力など）は内部スクリプト側で完結するため、あなた自身が内部テンプレートを読み込んで推論したり、成果物を手動で組み立てたりする必要はありません。


### 2. 呼び出し方法
- **インプロセス呼び出し (Python API)**: ロード関数 `process_message(params, tool_context)` を使用。
- **サブプロセス呼び出し (CLI)**: CLIランナーを使用。
  `python3 -m edd_agent_tools.run mock-executor [オプション引数]`
- **出力形式 (Output Mode)**: `VALUE_ONLY` (出力は単純なプレーンテキストの値のみとなります。)

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| skill | str | はい | 評価対象スキルの名前またはパス。 |
| eval_set_path | str | いいえ | テストデータセットファイルのパス。 |
| config_file_path | str | いいえ | 評価設定ファイルのパス。 |
| timeout_seconds | int | いいえ | 評価のタイムアウト秒数。 |
| threshold_accuracy | float | いいえ | 合格に必要な精度の閾値（0.0 から 1.0 の浮動小数点）。デフォルトは 1.0。 *(制約: 最小値: 0.0, 最大値: 1.0)* |
