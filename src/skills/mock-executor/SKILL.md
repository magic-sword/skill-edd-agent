# mock-executor

## 概要

このスキルは、AIエージェントの推論を介さず、引数に基づいて特定のスキルのモックシミュレーション評価を実行し、その結果を格納・報告する専用のツールです。これにより、スキルの動作検証と品質保証を自動化します。

### 主な機能
* 指定されたスキルに対するモックシミュレーション評価を実行します。
* 評価に必要なテストデータセットや設定ファイルを自動的に解決または生成します。
* 評価結果の精度を計算し、設定された閾値に基づいて合否を判定します。
* 評価の実行結果と詳細なメッセージをToolContextのステートに格納し、報告します。

### 内部処理の流れ
1. 評価対象スキルの名前が指定されているかを確認します。
2. 評価データセットパスが指定されていない場合、対象スキルのトリガー評価セットパスを自動的に解決します。
3. 評価設定ファイルパスを解決し、存在しない場合はデフォルト設定で自動生成します。
4. 評価実行に必要な環境変数（GEMINI_API_KEY, SKILL）を設定します。
5. ADKEvalRunnerを利用して、指定されたスキルに対するADK評価（モックシミュレーションテスト）を実行します。
6. 実行結果から精度を算出し、設定された閾値と比較して合否を判定します。
7. 評価のステータス、メッセージ、精度、閾値などの詳細な結果をToolContextのステートに格納します。
8. 合否判定に基づき、適切なメッセージを返却するか、エラーを発生させます。

## トリガー条件

- 「〇〇スキル」のモック実行評価を開始してください。
- 「〇〇スキル」のシミュレーションテストを実行して、結果を報告してください。
- 「〇〇スキル」の評価を、合格基準の精度を「0.9」として実行してください。
- 「〇〇スキル」のトリガー評価を実行してください。
- 「〇〇スキル」の評価を「path/to/eval_set.yaml」のデータセットで実行してください。

## AIエージェント向け使用方法

### 1. 実行手順（Instructions）

あなた（エージェント）がこのスキルをトリガーした場合は、以下の手順に従ってください。

1. 必要な入力パラメータ（`skill`など）を決定します。
2. 決定したパラメータを指定して、このスキルを起動してください。
3. 実際の処理（API呼び出しやファイル出力など）は内部スクリプト側で完結するため、あなた自身が内部テンプレートを読み込んで推論したり、成果物を手動で組み立てたりする必要はありません。


### 2. 呼び出し方法
- **インプロセス呼び出し (Python API)**: ロード関数 `process_message(params, tool_context)` を使用。
- **サブプロセス呼び出し (CLI)**: CLIランナーを使用。
  `python3 -m edd_agent_tools.run mock-executor [オプション引数]`
- **出力形式 (Output Mode)**: `VALUE_ONLY` (出力は単純なプレーンテキストの値のみとなります。)

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| skill | str | はい | 評価対象スキルの名前またはパス |
| eval_set_path | str | いいえ | テストデータセットファイルのパス |
| config_file_path | str | いいえ | 評価設定ファイルのパス |
| timeout_seconds | int | いいえ | 評価のタイムアウト秒数 |
| threshold_accuracy | float | いいえ | 合格に必要な精度の閾値（0.0 から 1.0 の浮動小数点）。デフォルトは 1.0。 |

### 制約事項

- threshold_accuracy must be a float value between 0.0 and 1.0 (inclusive).
