# skill-manager

## 概要

このスキルは、Google ADK 2.0 環境におけるスキルのTier（階層）およびメタデータの一元的な管理を行うためのツールです。AIエージェント（LLM）が直接推論を行うのではなく、指定された引数に基づいてPythonスクリプトが決定論的な処理を実行します。主な機能は以下の通りです。*   **スキル登録 (register)**: 新しいスキルをレジストリに登録します。デフォルトではTier 0として登録されます。*   **Tier取得 (get-tier)**: 指定されたスキルの現在のTier情報を取得します。*   **Tier設定 (set-tier)**: 指定されたスキルのTierを更新します。これにより、スキルの権限レベルを調整できます。*   **スキル一覧表示 (list)**: 現在レジストリに登録されている全てのスキルとその情報を一覧表示します。*   **メタデータ更新 (update-meta)**: 指定されたスキルのメタデータを更新します。このツールは、内部的に `skills_registry.json` ファイルを操作し、スキルの登録、Tierの変更、情報の取得などを行います。また、このスキルによって設定されたTier情報は、システム全体のセキュリティポリシー（例: `security.py` モジュール）によって、各スキルが利用できるファイル操作や他のスキル呼び出しといったツールセットの権限を動的に制限するために利用されます。これにより、ADK環境におけるスキルの安全な運用と権限管理が実現されます。

## トリガー条件

- スキルを新しく登録したい
- 〇〇スキルの現在のTierを教えて
- 〇〇スキルのTierを△に設定して
- 登録されているスキルの一覧を表示して
- 〇〇スキルのメタデータを更新して
- スキルレジストリを管理してほしい

## AIエージェント向け使用方法

### 1. 実行手順（Instructions）

あなた（エージェント）がこのスキルをトリガーした場合は、以下の手順に従ってください。

1. 必要な入力パラメータ（`command`など）を決定します。
2. 決定したパラメータを指定して、このスキルを起動してください。
3. 実際の処理（API呼び出しやファイル出力など）は内部スクリプト側で完結するため、あなた自身が内部テンプレートを読み込んで推論したり、成果物を手動で組み立てたりする必要はありません。


### 2. 呼び出し方法
- **インプロセス呼び出し (Python API)**: ロード関数 `process_message` を使用（状態の `validated_input` に `Input` スキーマを設定して実行）。
- **サブプロセス呼び出し (CLI)**: CLIランナーを使用。
  `python3 -m edd_agent_tools.cli.run skill-manager [オプション引数]`
- **出力形式 (Output Mode)**: `VALUE_ONLY` (出力は単純なプレーンテキストの値のみとなります。)

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| command | str | はい | 実行するコマンド ('register', 'get-tier', 'set-tier', 'list', 'update-meta') |
| skill | str | いいえ | 対象のスキル名 |
| tier | int | いいえ | 設定するTier (0, 1, 2, 3) |
| registry_path | str | いいえ | レジストリファイルのカスタムパス |

### 制約事項

- commandパラメータは必須です。
- commandが'register'の場合、skillパラメータは必須です。
- commandが'get-tier'の場合、skillパラメータは必須です。
- commandが'set-tier'の場合、skillとtierパラメータは必須です。
- commandが'update-meta'の場合、skillパラメータは必須です。
- tierパラメータが指定される場合、0, 1, 2, 3のいずれかの整数である必要があります。
