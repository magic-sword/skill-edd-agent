# skill-manager

## 概要

このスキルは、AIエージェントが直接推論するのではなく、引数に基づいてPythonスクリプトとして動作し、スキルの登録、Tier設定、メタデータ管理を一括で行うことを目的としています。これにより、スキルのライフサイクル管理を効率化し、セキュリティポリシーの適用を支援します。

### 主な機能
* 新しいスキルをレジストリに登録します
* 特定のスキルの現在のTierレベルを取得します
* 特定のスキルのTierレベルを設定または更新します
* 登録されているすべてのスキルとその情報を一覧表示します
* 特定のスキルのメタデータを更新します

### 内部処理の流れ
1. ユーザーからの入力パラメータ（コマンド、スキル名、Tier、レジストリパスなど）を受け取ります
2. 指定されたレジストリパス、またはデフォルトのパスを使用してスキルレジストリを初期化します
3. 入力されたコマンドに応じて、以下のいずれかの処理を実行します
4. スキル登録コマンドの場合、指定されたスキルをレジストリに登録します
5. Tier取得コマンドの場合、指定されたスキルの現在のTier情報を取得します
6. Tier設定コマンドの場合、指定されたスキルのTierを更新します
7. スキル一覧表示コマンドの場合、登録されているすべてのスキルを一覧表示します
8. メタデータ更新コマンドの場合、指定されたスキルのメタデータを更新します
9. 実行結果（成功/失敗、メッセージ、関連データ）をツールコンテキストに保存します
10. 処理結果のメッセージを返します

## トリガー条件

- 新しいスキルをシステムに登録してください
- 〇〇スキルの現在のTierレベルを教えてください
- 〇〇スキルのTierを3に設定してください
- 登録されているすべてのスキルとその情報をリストアップしてください
- 〇〇スキルのメタデータを最新の情報に更新してください
- スキルレジストリを管理したい

## AIエージェント向け使用方法

### 1. 実行手順（Instructions）

あなた（エージェント）がこのスキルをトリガーした場合は、以下の手順に従ってください。

1. 必要な入力パラメータ（`command`など）を決定します。
2. 決定したパラメータを指定して、このスキルを起動してください。
3. 実際の処理（API呼び出しやファイル出力など）は内部スクリプト側で完結するため、あなた自身が内部テンプレートを読み込んで推論したり、成果物を手動で組み立てたりする必要はありません。


### 2. 呼び出し方法
- **インプロセス呼び出し (Python API)**: ロード関数 `process_message(params, tool_context)` を使用。
- **サブプロセス呼び出し (CLI)**: CLIランナーを使用。
  `python3 -m edd_agent_tools.run skill-manager [オプション引数]`
- **出力形式 (Output Mode)**: `VALUE_ONLY` (出力は単純なプレーンテキストの値のみとなります。)

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| command | Literal['register', 'get-tier', 'set-tier', 'list', 'update-meta'] | はい | 実行するコマンド |
| skill | str | いいえ | 対象のスキル名 |
| tier | Literal['0', '1', '2', '3'] | いいえ | 設定するTier |
| registry_path | str | いいえ | レジストリファイルのカスタムパス |



### 制約事項

- commandが'register', 'get-tier', 'set-tier', 'update-meta'の場合、skillは必須です。
- commandが'set-tier'の場合、tierは必須です。
