# ケース変換ガイド

このドキュメントは、文字列を異なるケース形式に変換するための定義と具体的なルールを説明します。LLMが正確な変換ロジックを理解するために参照してください。

## 1. 大文字 (Upper Case)

### 定義
すべてのアルファベット文字を大文字に変換する形式です。

### 変換ルール
1.  入力文字列内のすべてのアルファベット文字を大文字に変換します。
2.  数字、記号、スペースなどの非アルファベット文字は変更しません。

### 例
*   `"hello world"` を大文字に変換すると `"HELLO WORLD"` になります。
*   `"FooBar123"` を大文字に変換すると `"FOOBAR123"` になります。
*   `"test_case"` を大文字に変換すると `"TEST_CASE"` になります。

## 2. 小文字 (Lower Case)

### 定義
すべてのアルファベット文字を小文字に変換する形式です。

### 変換ルール
1.  入力文字列内のすべてのアルファベット文字を小文字に変換します。
2.  数字、記号、スペースなどの非アルファベット文字は変更しません。

### 例
*   `"HELLO WORLD"` を小文字に変換すると `"hello world"` になります。
*   `"FooBar123"` を小文字に変換すると `"foobar123"` になります。
*   `"TEST_CASE"` を小文字に変換すると `"test_case"` になります。

## 3. キャメルケース (Camel Case)

### 定義
複合語の最初の単語は小文字で始め、それ以降の各単語の最初の文字を大文字にする形式です。単語間のスペースや区切り文字は削除します。

### 変換ルール
1.  入力文字列を単語に分割します。単語の区切りは、スペース、ハイフン (`-`)、アンダースコア (`_`)、または大文字と小文字の境界（例: `FooBar` は `Foo` と `Bar` に分割）とします。
2.  分割された単語のうち、最初の単語をすべて小文字に変換します。
3.  2番目以降の各単語について、最初の文字を大文字に、残りの文字を小文字に変換します。
4.  すべての変換された単語を連結し、区切り文字を削除します。

### 例
*   `"hello world"` をキャメルケースに変換すると `"helloWorld"` になります。
*   `"foo-bar-baz"` をキャメルケースに変換すると `"fooBarBaz"` になります。
*   `"some_variable_name"` をキャメルケースに変換すると `"someVariableName"` になります。
*   `"HTTPRequest"` をキャメルケースに変換すると `"httpRequest"` になります。

## 4. スネークケース (Snake Case)

### 定義
複合語の各単語をアンダースコア (`_`) で区切り、すべての文字を小文字にする形式です。

### 変換ルール
1.  入力文字列を単語に分割します。単語の区切りは、スペース、ハイフン (`-`)、または大文字と小文字の境界（例: `FooBar` は `Foo` と `Bar` に分割）とします。
2.  分割されたすべての単語を小文字に変換します。
3.  変換された単語間をアンダースコア (`_`) で連結します。

### 例
*   `"Hello World"` をスネークケースに変換すると `"hello_world"` になります。
*   `"fooBarBaz"` をスネークケースに変換すると `"foo_bar_baz"` になります。
*   `"some-variable-name"` をスネークケースに変換すると `"some_variable_name"` になります。
*   `"HTTPRequest"` をスネークケースに変換すると `"http_request"` になります。
