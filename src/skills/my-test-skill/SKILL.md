# スキル仕様書: my-test-skill

## 概要

引数aとbの合計を計算します。

### 主な機能
* 2つの整数を足し算し、その合計値を計算します。

### 内部処理の流れ
1. ユーザーから入力された2つの整数 `a` と `b` を受け取ります。
2. 内部の `SkillExecutor` クラスのインスタンスを生成します。
3. `SkillExecutor` インスタンスの `add_numbers` メソッドを呼び出し、引数 `a` と `b` を渡します。
4. `add_numbers` メソッド内で、受け取った `a` と `b` を足し算します。
5. 計算された合計値を `AddNumbersOutput` オブジェクトに格納し、結果として返却します。
