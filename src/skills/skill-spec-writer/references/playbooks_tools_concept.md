# Google Cloud Playbooksにおけるツールの概念と実行モデル

本ドキュメントは、Google Cloud Conversational Agents (Playbooks) におけるツールの定義、および実行モデル（同期/非同期）の思想についてまとめたリファレンス資料です。
ADK（Agent Development Kit）が採用している `"tool"` および `"agent"` の概念的背景を理解するために参照してください。

---

## 1. ツール（Tool）の役割と分類

Playbooks におけるツールは、エージェントが外部環境と対話するための主要なインターフェースです。
ツールは技術的な実装や目的によって、以下のようなUnionフィールドとして定義されています。

* **`pythonFunction`**: Python で書かれた任意のスクリプト処理を実行するツール（決定論的）。
* **`agentTool`**: 別の自律的エージェント（Sub-Agent）を呼び出し、複雑なサブタスクをLLM推論を通じて委譲するツール（非決定論的）。
* **`openApiTool`**: OpenAPI 仕様に従った外部のWeb APIを実行するツール。
* **`googleSearchTool`**: Google検索結果をコンテキストにアタッチするシステム提供のツール。

---

## 2. 実行タイプ（Execution Type）

ツールの呼び出しがエージェントの会話（推論）フローをブロックするかどうかに応じて、2つの実行タイプがサポートされています。

### ① 同期実行（Synchronous Execution）
* **動作**: ツールが応答を返すまで、エージェントの回答生成プロセスが**完全にブロック（停止）**されます。
* **ユースケース**: 低レイテンシ（5秒未満）で終了するツールで、その結果がないと後続の会話を進められない場合に使用します。

### ② 非同期実行（Asynchronous Execution）
* **動作**: ツールの実行がトリガーされても、エージェントの会話フローはブロックされません。
* **ユースケース**: 高レイテンシ（5〜60秒）の処理に使用します。
* **フロー**:
  1. エージェントがツールを起動。
  2. ツールは即座に `"status": "pending"`（保留中）のレスポンスを返す。
  3. エージェントは「データを処理中ですので、少々お待ちください」などの応答をし、会話を継続できる。
  4. 最終的な実行結果が利用可能になると、次の会話ターンで `<context>` タグを介して結果がエージェントの推論コンテキストに自動挿入される。
