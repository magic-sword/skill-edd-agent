# skill-spec-writer

設計情報（Pydanticスキーマ等）を動的にロードし、ADK 2.0仕様に準拠したSKILL.mdを生成します。

## 概要

既存のスキル設計情報（design.json）を基に、ADK 2.0に準拠したSKILL.md仕様書を自動生成します。これにより、開発者はドキュメント作成の手場を省き、常に最新かつ正確なスキル仕様書を維持できます。

### 主な機能
* 既存のスキル設計情報（design.json）を読み込み、ADK 2.0仕様に準拠したSKILL.mdを生成します。
* 対象スキルの設計情報パスまたはスキル名を指定して、仕様書生成の対象を特定します。
* 生成されたSKILL.mdの保存先ディレクトリを指定できます。
* 実装ソースコードを解析し、仕様書に含めることができます。
* 仕様書生成時の表現に関する追加の指示（プロンプト）を適用できます。
* 開発者のドキュメント作成の手間を削減し、常に最新かつ正確なスキル仕様書を維持することを支援します。

### 内部処理の流れ
1. スキル名またはdesign.jsonのパスが提供されていることを検証します。
2. 指定されたスキル名またはパスから、対象スキルの設計情報（design.json）をロードします。
3. 出力ディレクトリとソースコードディレクトリのパスを解決します（指定がない場合はデフォルト値を使用）。
4. スキルの実行タイプ（この場合はtool）に基づいて、適切な仕様書ライター（ToolSpecWriter）を初期化します。
5. 共通のプロンプトテンプレートとスキル設計情報を組み合わせて、LLMに渡すプロンプトを構築します。
6. 必要に応じて、指定されたソースコードディレクトリの内容をプロンプトに添付します。
7. LLM（Gemini API）を呼び出し、スキルの目的、機能、トリガー条件、内部処理フローなどの非決定論的なテキスト要素を抽出します。
8. 抽出されたテキスト要素と決定論的な設計情報（パラメータ、制約など）を組み合わせて、ADK 2.0に準拠したSKILL.mdのMarkdownコンテンツを生成します。
9. 生成されたMarkdownコンテンツを、指定された出力ディレクトリに「SKILL.md」として保存します。
10. 処理結果（成功/失敗、メッセージ、出力パス）を返却します。

## トリガー条件

- SKILL.mdを生成してほしい
- このスキルの仕様書を作って
- design.jsonからSKILL.mdを作成
- スキル定義書を自動生成
- ADK 2.0のSKILL.mdを生成

## 公開関数 (APIエンドポイント)

### generate_skill_spec

既存のスキル設計情報（design.json）を基に、ADK 2.0に準拠したSKILL.md仕様書を自動生成します。

#### 実行方法

この関数は、与えられた入力パラメータに基づき、事前に定義されたスクリプトを実行する決定論的なツールです。
実行時には、LLMは必要なパラメータ（`design_path`, `skill`など）を適切に抽出し、このツールを呼び出す必要があります。

#### 入力パラメータ

| パラメータ名 | 型 | 必須 | デフォルト値 | 説明 |
|---|---|---|---|---|
| design_path | str | いいえ | - | design.json ファイルの直接のパス。省略された場合は skill から自動探索します。 |
| skill | str | いいえ | - | 対象の既存スキル名。design_path 省略時の自動探索キーとして使用されます。 *(制約: パターン: `^[a-z0-9]+(?:-[a-z0-9]+)*$`)* |
| output_dir | str | いいえ | - | 生成されたSKILL.mdを保存するディレクトリのパス。省略時は対象スキルのディレクトリに出力されます。 |
| source_code_dir | str | いいえ | - | 実装ソースコードが格納されたディレクトリパス（または単一ファイル）。指定しない場合、自動的にスキルの scripts ディレクトリを探索します。 |
| prompt | str | いいえ | - | 仕様書生成における、特別に明記したい追加の表現上のこだわりや注意点などの指示。 |

> [!NOTE]
> **`prompt` パラメータの使用ガイドライン:**
> * **指定可能な指示**: 生成される仕様書のテキスト説明のトーンや粒度（例: 開発者向けに詳細に、あるいは初心者向けに簡単に書く）、特別に言及してほしいセキュリティ設計や注意点の強調を指定できます。
> * **構造的な制約（指定不可）**: 仕様書のマークダウンレイアウト構成（見出しの順序、テーブル項目）は決定論的テンプレートに固定されているため、プロンプト指示によって構成そのものを変更することはできません。

#### 出力仕様

* **出力モード**: `STRUCTURED_JSON`

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| status | Literal['success', 'failed'] | はい | スキルの実行結果ステータス。'success' または 'failed'。 |
| message | str | はい | 実行結果に関する詳細メッセージ。 |
| output_dir | str | はい | 仕様書(SKILL.md)が格納されたスキルディレクトリの絶対パス |
