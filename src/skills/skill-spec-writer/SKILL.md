# skill-spec-writer

## 概要

このスキルは、設計情報（Pydanticスキーマ等）を動的にロードし、Google ADK 2.0仕様に準拠したSKILL.mdを生成する決定論的なツールです。AIエージェントの推論を介さず、与えられた引数に基づいて仕様書作成処理を完結させます。

### 主な機能
* ADK 2.0仕様に準拠したSKILL.mdファイルを自動生成します。
* スキルの設計情報（Pydanticスキーマ等）を解析し、パラメータや依存関係を抽出します。
* LLM（Gemini API）を利用して、スキルの目的、機能、トリガー条件などの人間が理解しやすい説明文を生成します。
* スキルの実行タイプ（ツールまたはエージェント）に応じた適切な仕様書フォーマットで出力します。
* 生成されたSKILL.mdファイルを指定されたディレクトリに保存します。

### 内部処理の流れ
1. 入力パラメータ（スキル名または設計パス）に基づいて対象スキルの設計情報とディレクトリを特定しロードします。
2. 出力ディレクトリとソースコードディレクトリのパスを解決します。
3. スキルの実行タイプ（toolまたはagent）に応じた適切な仕様書ライター（SpecWriter）を生成します。
4. LLM（Gemini API）に渡すプロンプトを構築し、ソースコードを添付して、スキルの目的、機能、トリガー条件、ワークフローなどの非決定論的な説明文を抽出させます。
5. 抽出された情報と、設計情報から決定論的に取得したパラメータ、依存関係、出力モードなどを組み合わせて、Markdown形式のSKILL.mdコンテンツをレンダリングします。
6. 生成されたMarkdownコンテンツを、指定された出力ディレクトリにSKILL.mdファイルとして保存します。

## トリガー条件

- 「〇〇スキルのSKILL.mdを生成してください」
- 「このスキルの仕様書を作成してほしい」
- 「指定された設計パスからSKILL.mdを生成して」
- 「スキル定義ファイルに基づいて仕様書を書き出してください」
- 「`my-skill`の仕様書を`output/`ディレクトリに作成して」
- 「ソースコードディレクトリ`src/`を使って、`design.json`から仕様書を生成して」

## AIエージェント向け使用方法

### 1. 実行手順（Instructions）

あなた（エージェント）がこのスキルをトリガーした場合は、以下の手順に従ってください。

1. 必要な入力パラメータ（`design_path`, `skill`など）を決定します。
2. 決定したパラメータを指定して、このスキルを起動してください。
3. 実際の処理（API呼び出しやファイル出力など）は内部スクリプト側で完結するため、あなた自身が内部テンプレートを読み込んで推論したり、成果物を手動で組み立てたりする必要はありません。


### 2. 呼び出し方法
- **インプロセス呼び出し (Python API)**: ロード関数 `process_message(params, tool_context)` を使用。
- **サブプロセス呼び出し (CLI)**: CLIランナーを使用。
  `python3 -m edd_agent_tools.run skill-spec-writer [オプション引数]`
- **出力形式 (Output Mode)**: `STRUCTURED_JSON` (特定のJSONスキーマ構造に厳密に従った構造化データを出力します。生成結果のパース成功時に生成されたファイルのパスや、エラー時にはエラーメッセージと詳細情報が含まれます。)

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| design_path | str | いいえ | design.json ファイルの直接のパス。省略された場合は skill から自動探索します。 |
| skill | str | いいえ | 対象の既存スキル名。design_path 省略時の自動探索キーとして使用されます。 |
| output_dir | str | いいえ | 生成されたSKILL.mdを保存するディレクトリのパス。省略時は対象スキルのディレクトリに出力されます。 |
| source_code_dir | str | いいえ | 実装ソースコードが格納されたディレクトリパス（または単一ファイル）。指定しない場合、自動的にスキルの scripts ディレクトリを探索します。 |

### 出力パラメータ (構造化JSONの戻り値構造)

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| status | Literal['success', 'failed'] | はい | スキルの実行結果ステータス。'success' または 'failed'。 |
| message | str | はい | 実行結果に関する詳細メッセージ。 |
| output_file_path | str | いいえ | 生成されたSKILL.mdファイルの絶対パス。成功時にのみ存在し、失敗時はnull。 |

### 制約事項

- skill と design_path のいずれか一方は必ず指定する必要があります。
