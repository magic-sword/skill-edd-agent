# スキル仕様書: skill-spec-writer

## 概要

既存のスキル設計情報（design.json）を基に、ADK 2.0に準拠したSKILL.md仕様書を自動生成します。これにより、開発者はドキュメント作成の手場を省き、常に最新かつ正確なスキル仕様書を維持できます。

### 主な機能
* 既存のスキル設計情報（design.json）を基に、ADK 2.0に準拠したSKILL.md仕様書を自動生成します。
* 開発者が手動でドキュメントを作成する手間を省き、ドキュメント作成プロセスを自動化します。
* 常に最新かつ正確なスキル仕様書を維持し、ドキュメントの陳腐化を防ぎます。
* スキルタイプ（tool, agent, workflow）に応じた適切な仕様書テンプレートと内容で生成します。

### 内部処理の流れ
1. 入力されたスキル名または設計ファイルのパスから、対象スキルのディレクトリ構造と設計情報（design.json）を特定しロードします。
2. 出力ディレクトリとソースコードスキャン対象ディレクトリのパスを解決します。
3. スキルの実行タイプ（tool, agent, workflow）に基づいて、適切な仕様書生成ライター（SpecWriter）を初期化します。
4. 設計情報とソースコード（存在する場合）を基に、LLM（Gemini）へ仕様書生成のためのプロンプトを構築し送信します。
5. LLMからの応答をパースし、「主要機能」「トリガー条件」「内部処理の流れ」といった非決定論的な説明要素を抽出します。
6. 抽出された情報と決定論的な設計情報（パラメータ定義など）を組み合わせて、ADK 2.0に準拠したSKILL.mdファイルをMarkdown形式で構築します。
7. 生成されたSKILL.mdを指定された出力ディレクトリに保存し、結果（成功/失敗、メッセージ、出力パス）を返却します。

## トリガー条件

このスキルは、以下の条件やプロンプトでトリガーされます。

- ADK 2.0仕様書を生成したい
- SKILL.mdを作成してほしい
- スキル設計書を自動生成する
- 既存のスキル設計情報から仕様書を生成する
- 特定のスキル（例: `my-awesome-skill`）の仕様書を生成したい
- 設計ファイル（例: `path/to/my-skill/design.json`）から仕様書を生成したい

## 公開関数

### generate_skill_spec

既存のスキル設計情報（design.json）を基に、ADK 2.0に準拠したSKILL.md仕様書を自動生成します。

#### 実行方法
${skill_name} は、与えられたパラメータに基づいて特定のタスクを**決定論的に実行**するツールです。LLMが推論を挟まず、直接このツールを呼び出して指示通りの操作を行います。

利用例：
${skill_name}(`design_path`, `skill`)

#### 入力パラメータ
| パラメータ名 | 型 | 必須 | デフォルト値 | 説明 |
|---|---|---|---|---|
| design_path | str | いいえ | - | design.json ファイルの直接のパス。省略された場合は skill から自動探索します。 |
| skill | str | いいえ | - | 対象の既存スキル名。design_path 省略時の自動探索キーとして使用されます。 *(制約: パターン: `^[a-z0-9]+(?:-[a-z0-9]+)*$`)* |
| output_dir | str | いいえ | - | 生成されたSKILL.mdを保存するディレクトリのパス。省略時は対象スキルのディレクトリに出力されます。 |
| source_code_dir | str | いいえ | - | 実装ソースコードが格納されたディレクトリパス（または単一ファイル）。指定しない場合、自動的にスキルの scripts ディレクトリを探索します。 |
| prompt | str | いいえ | - | 仕様書生成における、特別に明記したい追加の表現上のこだわりや注意点などの指示。 |


> [!NOTE]
> **`prompt` パラメータの使用ガイドライン:**
> * **指定可能な指示**: 生成される仕様書のテキスト説明のトーンや粒度（例: 開発者向けに詳細に、あるいは初心者向けに簡単に書く）、特別に言及してほしいセキュリティ設計や注意点の強調を指定できます。
> * **構造的な制約（指定不可）**: 仕様書のマークダウンレイアウト構成（見出しの順序、テーブル項目）は決定論的テンプレートに固定されているため、プロンプト指示によって構成そのものを変更することはできません。


#### 出力仕様
* **出力モード**: `STRUCTURED_JSON`
| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| status | Literal['success', 'failed'] | はい | スキルの実行結果ステータス。'success' または 'failed'。 |
| message | str | はい | 実行結果に関する詳細メッセージ。 |
| output_dir | str | はい | 仕様書(SKILL.md)が格納されたスキルディレクトリの絶対パス |
