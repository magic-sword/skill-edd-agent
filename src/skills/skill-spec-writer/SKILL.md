# skill-spec-writer

## 概要

このスキルは、Google ADK 2.0 互換のスキル仕様書である SKILL.md を自動生成するためのツールです。開発者がスキルを定義する際に作成する設計情報（design.json）と、実装コードを基に、人間が理解しやすい詳細なドキュメントを生成します。

主な機能と動作は以下の通りです。

*   **入力情報の受け取り:** 対象となるスキル名、または design.json ファイルのパス、出力先ディレクトリ、および実装ソースコードのディレクトリパスをパラメータとして受け取ります。
*   **設計情報のロード:** 指定されたスキル名またはパスから、スキルの設計情報（design.json）を動的にロードします。
*   **LLMによるコンテンツ生成:** ロードした設計情報（パラメータ、依存関係など）と、添付された実装ソースコードを分析し、大規模言語モデル（LLM）を活用して、スキルの「概要」や「トリガー条件」といった人間向けの非決定論的な説明文を生成します。
*   **Markdownドキュメントの構築:** LLMが生成したコンテンツと、設計情報から決定論的に抽出できる情報（パラメータテーブル、実行方法、出力モードの詳細など）を組み合わせて、最終的な SKILL.md ファイルをMarkdown形式で構築します。
*   **ファイル出力:** 生成された SKILL.md は、指定された出力ディレクトリに保存されます。出力ディレクトリが省略された場合は、対象スキルのルートディレクトリに出力されます。

このスキルは、引数に基づいてPythonスクリプトが処理を完結させる「ツール」として機能します。AIエージェントが自律的に推論するのではなく、与えられた情報に基づいて仕様書生成という具体的なタスクを実行します。

## トリガー条件

- SKILL.md を生成してほしい
- スキルの仕様書を作成してください
- このスキルのドキュメントを自動生成して
- ADK 2.0 形式の仕様書を出力して
- スキル定義ファイルを元にドキュメントを作って
- 指定したスキルのSKILL.mdを生成する

## AIエージェント向け使用方法

### 1. 実行手順（Instructions）

あなた（エージェント）がこのスキルをトリガーした場合は、以下の手順に従ってください。

1. 必要な入力パラメータ（パラメータなど）を決定します。
2. 決定したパラメータを指定して、このスキルを起動してください。
3. 実際の処理（API呼び出しやファイル出力など）は内部スクリプト側で完結するため、あなた自身が内部テンプレートを読み込んで推論したり、成果物を手動で組み立てたりする必要はありません。


### 2. 呼び出し方法
- **インプロセス呼び出し (Python API)**: ロード関数 `process_message` を使用（状態の `validated_input` に `Input` スキーマを設定して実行）。
- **サブプロセス呼び出し (CLI)**: CLIランナーを使用。
  `python3 -m edd_agent_tools.cli.run skill-spec-writer [オプション引数]`
- **出力形式 (Output Mode)**: `STRUCTURED_JSON` (特定のJSONスキーマ構造に厳密に従った構造化データを出力します。生成結果のパース成功時に生成されたファイルのパスや、エラー時にはエラーメッセージと詳細情報が含まれます。)

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| design_path | str | いいえ | design.json ファイルの直接のパス。省略された場合は name から自動探索します。 |
| name | str | いいえ | 対象の既存スキル名。design_path 省略時の自動探索キーとして使用されます。 |
| output_dir | str | いいえ | 生成されたSKILL.mdを保存するディレクトリのパス。省略時は対象スキルのディレクトリに出力されます。 |
| source_code_dir | str | いいえ | 実装ソースコードが格納されたディレクトリパス（または単一ファイル）。指定しない場合、自動的にスキルの scripts ディレクトリを探索します。 |

### 制約事項

- name と design_path のいずれか一方は必ず指定する必要があります。
