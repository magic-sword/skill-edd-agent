# skill-spec-writer

## 概要

このスキルは、Google ADK 2.0 互換のスキル仕様書（SKILL.md）を自動生成するためのツールです。AIエージェント（LLM）が直接推論するのではなく、与えられた引数に基づいてPythonスクリプトが決定論的に処理を実行します。開発者が手動で記述する手間を省き、スキル設計と実装コードから最新かつ正確な仕様書を効率的に生成することを目的としています。主な機能と動作フローは以下の通りです。

- **入力パラメータの受け付けと検証**: `design_path`（design.jsonへのパス）、`skill`（対象スキル名）、`output_dir`（出力先ディレクトリ）、`source_code_dir`（ソースコードディレクトリ）などのパラメータを受け取り、Pydanticモデルで厳密に検証します。`skill`または`design_path`のいずれか一方は必須です。
- **スキル情報の特定とロード**: スキルレジストリから対象スキルのディレクトリを特定し、`design.json`ファイルから設計メタデータ（`SkillDesign`）をロードします。
- **出力パスの解決**: `output_dir`や`source_code_dir`が省略された場合、スキルのデフォルトディレクトリを基に適切なパスを解決します。
- **ライターの動的選択**: ロードした設計メタデータに含まれる`execution_type`（例: `tool`、`agent`）に基づき、`SpecWriterFactory`を使用して適切な仕様書ライター（`ToolSpecWriter`または`AgentSpecWriter`）を動的に生成します。
- **LLMによる非決定論的情報の抽出**: 選択されたライターは、スキル名、パラメータ、依存関係、および対象スキルの実装ソースコード（Pythonファイルのみ）を含むプロンプトを構築します。このプロンプトとソースコードをGemini API（`gemini-2.5-flash`）に送信し、`human_overview`（人間向け概要）や`trigger_conditions`（トリガー条件）といった非決定論的なテキスト情報を構造化されたJSON形式で抽出します。
- **SKILL.mdの生成と保存**: 抽出された情報と、スキル名、機械的な説明、パラメータテーブル、実行指示、出力モードなどの決定論的な情報を組み合わせて、Markdownテンプレートを用いて最終的な`SKILL.md`ファイルを生成します。生成されたファイルは指定された`output_dir`に保存されます。
- **結果の通知**: 生成の成功または失敗、および出力ファイルのパスをツールコンテキストに記録し、呼び出し元に通知します。

## トリガー条件

- スキルの仕様書を生成して
- SKILL.mdを作成してください
- 〇〇スキル（例: `my-awesome-skill`）の仕様書を生成したい
- design.json から SKILL.md を作成して
- スキルのドキュメントを生成してほしい
- 〇〇（スキル名）のSKILL.mdを更新して

## AIエージェント向け使用方法

### 1. 実行手順（Instructions）

あなた（エージェント）がこのスキルをトリガーした場合は、以下の手順に従ってください。

1. 必要な入力パラメータ（パラメータなど）を決定します。
2. 決定したパラメータを指定して、このスキルを起動してください。
3. 実際の処理（API呼び出しやファイル出力など）は内部スクリプト側で完結するため、あなた自身が内部テンプレートを読み込んで推論したり、成果物を手動で組み立てたりする必要はありません。


### 2. 呼び出し方法
- **インプロセス呼び出し (Python API)**: ロード関数 `process_message` を使用（状態の `validated_input` に `Input` スキーマを設定して実行）。
- **サブプロセス呼び出し (CLI)**: CLIランナーを使用。
  `python3 -m edd_agent_tools.cli.run skill-spec-writer [オプション引数]`
- **出力形式 (Output Mode)**: `STRUCTURED_JSON` (特定のJSONスキーマ構造に厳密に従った構造化データを出力します。生成結果のパース成功時に生成されたファイルのパスや、エラー時にはエラーメッセージと詳細情報が含まれます。)

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| design_path | str | いいえ | design.json ファイルの直接のパス。省略された場合は skill から自動探索します。 |
| skill | str | いいえ | 対象の既存スキル名。design_path 省略時の自動探索キーとして使用されます。 |
| output_dir | str | いいえ | 生成されたSKILL.mdを保存するディレクトリのパス。省略時は対象スキルのディレクトリに出力されます。 |
| source_code_dir | str | いいえ | 実装ソースコードが格納されたディレクトリパス（または単一ファイル）。指定しない場合、自動的にスキルの scripts ディレクトリを探索します。 |

### 制約事項

- skill と design_path のいずれか一方は必ず指定する必要があります。
