# skill-spec-writer

## 概要

このスキルは、AIエージェントが直接推論するのではなく、引数として与えられた設計情報（Pydanticスキーマ等）とソースコードを基に、ADK 2.0仕様に準拠したSKILL.mdを動的に生成し、処理を完結させるツールです。

### 主な機能
* ADK 2.0仕様に準拠したSKILL.mdを自動生成します。
* Pydanticスキーマや設計情報からスキル仕様を動的に抽出します。
* スキルの実行タイプ（tool/agent）に応じて適切な仕様書を生成します。
* 入力パラメータや出力パラメータの詳細な説明を自動で記述します。
* ソースコードを解析し、LLMを活用して非決定論的な説明文（目的、機能、トリガー条件、ワークフロー）を生成します。

### 内部処理の流れ
1. 入力されたパラメータ（スキル名、設計ファイルのパス、出力ディレクトリ、ソースコードディレクトリなど）を検証し、不足している場合は自動で解決します。
2. 指定されたスキル名または設計パスから、対象スキルのディレクトリ構造を特定し、`design.json`から設計メタデータをロードします。
3. スキルの`execution_type`（toolまたはagent）に基づいて、適切な仕様書ライター（`ToolSpecWriter`または`AgentSpecWriter`）を構築します。
4. 共通のプロンプトテンプレートと、スキルタイプ固有の指示、およびユーザーからの追加指示を組み合わせて、LLMに渡すプロンプトを構築します。
5. 対象スキルのソースコードディレクトリをLLMへの入力として添付し、LLM（Gemini API）を呼び出して、目的、機能、トリガー条件、ワークフローなどの非決定論的なテキスト情報を構造化JSON形式で抽出します。
6. 抽出されたテキスト情報と、設計メタデータ（パラメータ、依存関係、出力モードなど）を組み合わせて、ADK 2.0仕様に準拠したMarkdown形式のSKILL.mdドキュメントをレンダリングします。
7. 生成されたSKILL.mdを指定された出力ディレクトリに保存し、そのファイルパスを返します。

## トリガー条件

- このスキルの仕様書を生成して
- skill-spec-writerのSKILL.mdを作成してください
- 指定された設計ファイルに基づいて仕様書を出力して
- スキル定義から仕様書を自動生成したい
- `my-skill`というスキルの仕様書を生成してほしい
- `design.json`のパスを指定して仕様書を作成して

## AIエージェント向け使用方法

### 1. 実行手順（Instructions）

あなた（エージェント）がこのスキルをトリガーした場合は、以下の手順に従ってください。

1. 必要な入力パラメータ（`prompt`, `design_path`など）を決定します。
2. 決定したパラメータを指定して、このスキルを起動してください。
3. 実際の処理（API呼び出しやファイル出力など）は内部スクリプト側で完結するため、あなた自身が内部テンプレートを読み込んで推論したり、成果物を手動で組み立てたりする必要はありません。


### 2. 呼び出し方法
- **インプロセス呼び出し (Python API)**: ロード関数 `process_message(params, tool_context)` を使用。
- **サブプロセス呼び出し (CLI)**: CLIランナーを使用。
  `python3 -m edd_agent_tools.run skill-spec-writer [オプション引数]`
- **出力形式 (Output Mode)**: `STRUCTURED_JSON` (特定のJSONスキーマ構造に厳密に従った構造化データを出力します。生成結果のパース成功時に生成されたファイルのパスや、エラー時にはエラーメッセージと詳細情報が含まれます。)

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| prompt | str | いいえ | 仕様書生成における、特別に明記したい追加の表現上のこだわりや注意点などの指示。 |
| design_path | str | いいえ | design.json ファイルの直接のパス。省略された場合は skill から自動探索します。 |
| skill | str | いいえ | 対象 of 既存スキル名。design_path 省略時の自動探索キーとして使用されます。 |
| output_dir | str | いいえ | 生成されたSKILL.mdを保存するディレクトリのパス。省略時は対象スキルのディレクトリに出力されます。 |
| source_code_dir | str | いいえ | 実装ソースコードが格納されたディレクトリパス（または単一ファイル）。指定しない場合、自動的にスキルの scripts ディレクトリを探索します。 |

### 出力パラメータ (構造化JSONの戻り値構造)

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| status | str | はい | スキルの実行結果ステータス。'success' または 'failed'。 |
| message | str | はい | 実行結果に関する詳細メッセージ。 |
| output_file_path | str | いいえ | 生成されたSKILL.mdファイルの絶対パス。成功時にのみ存在し、失敗時はnull。 |

### 制約事項

- パラメータ 'skill' または 'design_path' のいずれか一方は必ず指定する必要があります。
