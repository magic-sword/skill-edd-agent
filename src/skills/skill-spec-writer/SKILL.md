# skill-spec-writer

## 概要

このスキルは、設計情報（Pydanticスキーマ等）を動的にロードし、Google ADK 2.0仕様に準拠したSKILL.mdを自動生成するツールです。AIエージェントからの指示を受け、Pythonコードとして処理を完結させ、スキルの詳細な仕様書を作成します。

### 主な機能
* ADK 2.0仕様に準拠したSKILL.mdを自動生成します。
* スキルの設計情報（design.json）を動的に読み込み、仕様書に反映します。
* 実装ソースコードを解析し、LLMを用いてスキルの目的や機能、トリガー条件を自動抽出します。
* 入力パラメータや出力パラメータ、制約事項を含む詳細な仕様書を生成します。
* 生成されたSKILL.mdを指定されたディレクトリに保存します。

### 内部処理の流れ
1. 指定されたスキル名またはdesign.jsonパスから、対象スキルのディレクトリ構造を特定し、設計情報（design.json）をロードします。
2. SKILL.mdの出力先ディレクトリと、ソースコードの解析対象ディレクトリのパスを解決します。
3. スキルの実行タイプ（toolまたはagent）に基づいて、適切な仕様書ライター（ToolSpecWriterまたはAgentSpecWriter）を構築します。
4. LLMに渡すプロンプトを構築し、必要に応じて対象スキルのソースコードを添付します。
5. Gemini APIを呼び出し、スキルの目的、機能、処理手順、トリガー条件などの非決定論的な情報を構造化JSONとして抽出します。
6. 抽出された情報と決定論的な設計データ（パラメータ、依存関係など）を組み合わせて、SKILL.mdのMarkdownコンテンツを生成します。
7. 生成されたMarkdownコンテンツを、指定された出力ディレクトリにSKILL.mdとして保存します。

## トリガー条件

- 〇〇スキルの仕様書を生成してほしい
- このスキルのSKILL.mdを作成してください
- 設計情報からスキルのドキュメントを自動生成して
- 指定されたスキルについて、ADK 2.0形式の仕様書を出力してください
- スキル`my-skill`の仕様書を`./docs`ディレクトリに作成して
- `design.json`パス`/path/to/design.json`に基づいてSKILL.mdを生成して

## AIエージェント向け使用方法

### 1. 実行手順（Instructions）

あなた（エージェント）がこのスキルをトリガーした場合は、以下の手順に従ってください。

1. 必要な入力パラメータ（パラメータなど）を決定します。
2. 決定したパラメータを指定して、このスキルを起動してください。
3. 実際の処理（API呼び出しやファイル出力など）は内部スクリプト側で完結するため、あなた自身が内部テンプレートを読み込んで推論したり、成果物を手動で組み立てたりする必要はありません。


### 2. 呼び出し方法
- **インプロセス呼び出し (Python API)**: ロード関数 `process_message(params, tool_context)` を使用。
- **サブプロセス呼び出し (CLI)**: CLIランナーを使用。
  `python3 -m edd_agent_tools.run skill-spec-writer [オプション引数]`
- **出力形式 (Output Mode)**: `STRUCTURED_JSON` (特定のJSONスキーマ構造に厳密に従った構造化データを出力します。生成結果のパース成功時に生成されたファイルのパスや、エラー時にはエラーメッセージと詳細情報が含まれます。)

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| design_path | str | いいえ | design.json ファイルの直接のパス。省略された場合は skill から自動探索します。 |
| skill | str | いいえ | 対象の既存スキル名。design_path 省略時の自動探索キーとして使用されます。 |
| output_dir | str | いいえ | 生成されたSKILL.mdを保存するディレクトリのパス。省略時は対象スキルのディレクトリに出力されます。 |
| source_code_dir | str | いいえ | 実装ソースコードが格納されたディレクトリパス（または単一ファイル）。指定しない場合、自動的にスキルの scripts ディレクトリを探索します。 |

### 出力パラメータ (構造化JSONの戻り値構造)

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| status | str | はい | スキルの実行結果ステータス ('success' または 'failed') |
| message | str | はい | 実行結果のサマリーメッセージ |
| output_file_path | str | いいえ | 生成されたSKILL.mdファイルの絶対パス |

### 制約事項

- skill と design_path のいずれか一方は必ず指定する必要があります。
