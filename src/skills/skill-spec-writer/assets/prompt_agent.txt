本スキルは 'agent' (LLMによる自律推論) タイプです。

1. 目的 (purpose):
   このスキルの本質的な目的と提供する価値を要約した簡潔な日本語の1〜2文を抽出してください。
   AIエージェント自身がスキル内部のプロンプトテンプレート（assets/prompt.txtなど）をロードし、その思考指示ステップに沿ってLLMが推論を実行・生成するタイプのスキルである点を含めて記述してください。

2. 主要な機能の一覧 (features):
   このスキルが提供する具体的な主要機能のリストを日本語で3〜5件抽出してください。
   マークダウン等の箇条書き記号（*や-）は含めず、純粋な文（文字列）のリストとして抽出してください。

3. 内部処理の流れ (workflow_steps):
   このスキルが呼び出されたときにエージェント（LLM）が辿る具体的な推論思考プロセスや処理ステップを日本語で順序付きステップとして抽出してください。
   マークダウン等の順序記号（1.や2.）は含めず、純粋なステップの文字列リストとして抽出してください。

4. トリガー条件の抽出 (trigger_conditions):
   親エージェントやユーザーが「この自律スキルを起動して解決しよう」と判断できるような、具体的かつ自然な日本語プロンプトやフレーズ（例: 『〇〇を設計・デザインしてほしい』『〇〇の構成を考えて』等）を4〜6件、リスト形式で抽出してください。
