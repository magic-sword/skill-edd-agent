# trigger-evaluator

## 概要

このスキルは、指定されたGoogle ADK 2.0互換スキルのトリガー評価に必要なアセットを自動生成するためのツールです。AIエージェント（LLM）が直接推論するのではなく、引数として受け取ったスキル名に基づき、Pythonスクリプトとして一連の決定論的な処理を実行します。主な機能と内部処理の流れは以下の通りです。

*   **対象スキルのSKILL.md読み込み**: まず、入力されたスキル名に対応するスキルのSKILL.mdファイルを読み込みます。このファイルには、スキルの概要やトリガー条件などが記述されています。

*   **第1ゲート: トリガー条件の静的評価**: 読み込んだSKILL.mdの内容に基づき、内部でLLM（Gemini）を利用して、そのスキルのトリガー条件の「具体性（Specificity）」と「明確性（Clarity）」を5段階で評価します。両方の評価が4点以上である場合のみ、このゲートを通過し、次のステップに進みます。評価が不十分な場合はエラーとなり、処理が中断されます。

*   **第2ゲート: トリガー評価用テストケースの自動生成**: 静的評価を通過した後、再度LLM（Gemini）を活用し、SKILL.mdの内容から、そのスキルがトリガーされるべき「陽性プロンプト」と、トリガーされるべきではない「陰性プロンプト」をそれぞれ複数件自動生成します。これらのプロンプトは、Google ADKの評価フレームワークで利用可能な形式の評価セット（`eval_set.json`）として整形されます。

*   **アセットの保存とレポート生成**: 生成された評価セットと、それに対応する評価設定（`eval_config.json`）は、対象スキルの`tests/trigger`ディレクトリに保存されます。また、静的評価の結果、生成されたテストケースのパス、および全体の処理ステータスを含む詳細なレポート（`trigger_eval_report.json`）が、対象スキルの`tests`ディレクトリに保存されます。

このツールは、スキル開発者がトリガー条件の品質を確保し、評価プロセスを効率化するために設計されており、指定されたスキル名以外の入力は受け付けません。

## トリガー条件

- 「[スキル名]」スキルのトリガー条件を評価して
- 「[スキル名]」スキルのトリガー評価用テストケースを生成してほしい
- 「[スキル名]」のSKILL.mdのトリガー部分を静的に評価してください
- 「[スキル名]」のトリガーアセットを作成して
- 「[スキル名]」スキルのトリガーの具体性と明確性をチェックして
- 「[スキル名]」のトリガーテストを自動生成して

## AIエージェント向け使用方法

### 1. 実行手順（Instructions）

あなた（エージェント）がこのスキルをトリガーした場合は、以下の手順に従ってください。

1. 必要な入力パラメータ（`skill_name`など）を決定します。
2. 決定したパラメータを指定して、このスキルを起動してください。
3. 実際の処理（API呼び出しやファイル出力など）は内部スクリプト側で完結するため、あなた自身が内部テンプレートを読み込んで推論したり、成果物を手動で組み立てたりする必要はありません。


### 2. 呼び出し方法

このスキルは、インプロセス（Python関数のロード）による親エージェントとのシームレスな連携、およびCLIを用いた手動での検証実行をサポートします。

#### インプロセス呼び出し (Python API)
他の親エージェントから直接ロードして呼び出す場合は、以下のインターフェースを使用します。

* **ロード関数名**: `process_message`
* **入力状態 (`tool_context.state`)**:
  * `tool_context.state["validated_input"]` に、`Input` スキーマのインスタンス（検証済みオブジェクト）が設定されます。
* **出力状態 (`tool_context.state`)**:
  * 処理結果データが状態に直接書き込まれます。

#### サブプロセス呼び出し (CLI)
* **起動方法**: `python3 -m edd_agent_tools.cli.run --skill_name trigger-evaluator <引数>`
* **引数 (`args`)**:
  * Pydantic スキーマで定義されているパラメータをフラットなオプション引数として直接渡します（例: `--param_name value`）。

#### 出力形式の要件 (Output Mode)
- **Output Mode: VALUE_ONLY**
  出力は単純なプレーンテキストの値のみとなります。

### 入力パラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| skill_name | str | はい | 評価対象のスキル名 |



### 実行例

#### 1. インプロセス呼び出し (推奨)
親エージェントが本スキルを動的ロードしてプログラムから起動する推奨コード例です。

```python
# 1. スキルのロード
skill = load_skill("trigger-evaluator")

# 2. 状態に引数を設定して実行
# ※ 引数は validated_input 経由で process_message に渡されます
# tool_context.state["validated_input"] = Input(...)
skill.process_message(tool_context)
```

#### 2. サブプロセス呼び出し (手動テスト用 CLI)
開発環境などで本スキルを手動で動作確認する際の起動コマンド例です。

```bash
python3 -m edd_agent_tools.cli.run --skill_name trigger-evaluator --name "target-skill-name"
```
