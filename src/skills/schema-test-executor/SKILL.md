# スキル仕様書: schema-test-executor

## 概要

指定されたスキルと評価セットパスに基づき、スキーマ駆動の単体テストを実行し、その結果を返します。

### 主な機能
* 指定されたスキルに対してスキーマ駆動の単体テストを実行します。
* テスト対象のスキル名を指定できます。
* テストケースを定義したEvalCaseSetフォーマットのJSONファイルを指定できます。
* テスト実行の成功/失敗、概要フィードバック、詳細な結果（JSON形式）を返します。

### 内部処理の流れ
1. SkillManagerを使用して、指定されたスキル名に対応するSkillオブジェクトを取得します。
2. EvalSetLoaderを使用して、指定された評価セットパスのJSONファイルをロードし、EvalCaseSetオブジェクトにパースします。
3. SchemaDrivenTestRunnerを初期化します。
4. SchemaDrivenTestRunnerのrun_testsメソッドを呼び出し、Skillオブジェクト、EvalCaseSet、および実行環境を渡してテストを実行します。
5. テスト実行結果（EvalRunResult）から成功ステータス、フィードバック、詳細情報を抽出し、ExecuteSchemaTestOutputオブジェクトとして返します。
6. テスト実行中にエラーが発生した場合は、エラーメッセージを含む失敗結果を返します。

## 公開関数

### execute_schema_test

指定されたスキルと評価セットパスに基づき、スキーマ駆動の単体テストを実行し、その結果を返します。

#### 実行方法
${skill_name} は、与えられたパラメータに基づいて特定のタスクを**決定論的に実行**するツールです。LLMが推論を挟まず、直接このツールを呼び出して指示通りの操作を行います。

利用例：
${skill_name}(`skill_name`, `eval_set_path`, `env`)

#### 入力パラメータ
| パラメータ名 | 型 | 必須 | デフォルト値 | 説明 |
|---|---|---|---|---|
| skill_name | str | はい | - | テストを実行する対象スキルの名前。 *(制約: 最小長: 1)* |
| eval_set_path | str | はい | - | テストケースが記述されたEvalCaseSetフォーマットのJSONファイルへのパス。 *(制約: パターン: `^.*\.evalset\.json$`, 最小長: 1)* |
| env | str | はい | - | テスト実行環境。edd_agent_tools.WorkspaceEnvProtocol に準拠したオブジェクトがCLIランナーによって自動的に注入されます。 |


#### 出力仕様
* **出力モード**: `STRUCTURED_JSON`

| パラメータ名 | 型 | 必須 | 説明 |
|---|---|---|---|
| success | bool | はい | テスト実行が成功したかどうか。 |
| feedback | str | はい | テスト実行に関する概要フィードバックメッセージ。 |
| details | str | はい | テスト実行の詳細な結果（JSON文字列として表現）。 |
