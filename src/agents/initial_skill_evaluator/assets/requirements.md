# ワークフロー要件: initial_skill_evaluator

## ワークフロー全体の目的
このワークフローは、新しく生成されたスキルが適切に機能するかを最初に評価し、レジストリに登録されたスキルの初期ティアを設定することを目的とします。トリガーチェックとユニットテストを実行し、テスト結果に基づいてスキルのティアを昇格させます。

## 前提条件
- 評価対象となるスキルが生成されており、その情報が利用可能であること。

## 具体的な実行タスク手順 (ステップバイステップ)

1.  **スキル仮登録**: `set_skill_tier` コマンドを `'register'` で呼び出し、対象スキルが未登録であれば Tier 0 でレジストリに仮登録します。
2.  **トリガーテストケース生成**: `generate_trigger_tests` を呼び出し、対象スキルのトリガーチェックのためのテストケースを生成します。
3.  **トリガーテスト実行**: `run_skill_tests` を `eval_mode=0`、`threshold_accuracy=0.90` の設定で呼び出し、生成されたトリガーテストケースを実行します。
4.  **ユニットテストケース生成**: `generate_unit_tests` を呼び出し、対象スキルのユニットテストのためのテストケースを生成します。
5.  **ユニットテスト実行**: `run_skill_tests` を `eval_mode=1`、`threshold_accuracy=1.0` の設定で呼び出し、生成されたユニットテストケースを実行します。
6.  **スキルティア昇格**: `set_skill_tier` コマンドを `'set-tier'`、`tier=1` の設定で呼び出し、対象スキルが Tier 0 であれば Tier 1 へ昇格させます。
